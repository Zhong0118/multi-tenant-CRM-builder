### 未启用工作流的无效请求

记录详情页和抽屉原来都会请求 workflow 与 history。没有工作流时 API 返回 WORKFLOW_NOT_PUBLISHED / 409，查询默认重试三次，界面最后才隐藏这块区域。线上抽样日志里有大量这类请求；它不表示记录损坏或服务器宕机。

现在运行时 schema 返回 workflowEnabled，按已发布工作流计算。前端明确为 false 时不挂载工作流面板，也不留下空卡片；业务活动、跟进、关联不受影响。对旧 API 缺少该标记以及工作流取消发布的情况，409 不重试、不加载历史；其他暂时性故障保留重试和错误反馈。历史仅在工作流加载成功且不在重新验证时请求；已缓存成功后撤下流程的场景也有回归覆盖。

契约字段为可选布尔值，支持分批升级；没有新增数据库迁移，不向员工暴露完整流程配置。测试先复现多余请求，再验证页面和抽屉、旧 API 兼容及正常流程。
