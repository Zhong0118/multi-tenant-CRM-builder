# AI 查询与批量负责人本地验收

日期：2026-10-15。状态：本地实现、测试、真实 AI 联调与审查完成；未提交、推送或部署服务器。

## 本轮改动

- 负责人批量分配上限从 100 提高到 **1000 条**。按实际勾选数量处理，不要求凑满一页；普通字段批量编辑仍为 100 条，换页清空选择的规则不变。
- 延用逐条负责人接口和版本校验，保留成功/失败进度，重试只处理失败项。1001 条会被界面和提交前检查拒绝；没有新增批量后端接口或绕过权限。
- 为 AI 的筛选参数提供实际格式约束和纠正指引：例如单选条件必须是选项 key 数组。保留原有可见字段、选项和记录权限校验，没有对“已流失”业务值做特殊硬编码。
- 区分无效查询参数、访问受限、查询预算和服务异常。模型获得安全的纠正指引，界面获得简洁错误说明，不返回原始异常、隐藏字段或堆栈。SDK 在工具执行前拒绝参数的失败也会记录。
- 在最多四轮工具步骤后预留一次禁止工具调用的总结步骤，保留六次工具执行、超时和数据量限制。空答案、工具调用结束但无答案、截断答案不再当作成功。
- 新步骤开始时清除前一步过程文字，保留查询状态和来源；最终保存完整的最后一步答案。要求直接回答实际数据、说明字段口径，不能用少量搜索结果冒充完整合计。
- 对话过程区显示成功、失败、中断及耗时，支持展开核对；本轮读取到的业务表名称用于查询标签和来源。调整会话列表、回答、输入区、来源图标及过渡，沿用现有主题。
- 局部失败可通过原重试接口重试；已有写操作提案的轮次仍不能重试，不绕过确认。运行中重复点击不会启动并发重试。
- 本次尝试和工具耗时停止后冻结；旧历史缺少可靠时间时不编造计时，重试不把中间等待时间算进去。

## 追加：对话锚点与业务表滚动（本地）

- AI 对话区和会话列表隐藏原生滚动条，保留滚轮、触摸和键盘滚动。右侧每个圆点对应一条已加载的用户提问，悬停显示摘要，点击平滑定位并标记当前位置；系统要求减少动画时直接定位。
- 修复平滑向上跳转刚离开底部时，被自动跟随拉回底部的问题。阅读历史时新增回答不会强制滚到底部；可通过“回到最新”恢复跟随。切换会话重置滚动状态。
- 业务表采用固定筛选区、表头和分页，表格内容独立滚动；固定操作列不会覆盖表头。手机继续显示卡片，记录区独立滚动；屏幕较矮或筛选项较多时，顶部控件区也可独立滚动，保证所有控件可访问。
- 相关 3 个测试文件共 **85 tests passed**；Web typecheck、受影响 TS/TSX ESLint、Web build 和 `git diff --check` 通过。
- 浏览器验证 1440×1000、390×844 和 844×390。桌面记录滚动 200px 后表头、筛选区和分页位置不变；手机无横向溢出，分页留在视口内。12 轮对话的浏览器临时响应验证首个/中间提问定位、当前项与回到底部；真实历史恢复后复核正常。
- 本次未调用真实 AI Provider、未修改业务记录、未迁移数据库，也未同步 GitHub 或服务器。临时浏览器响应拦截与测试登录会话均已清理。截图及测试输出位于被 Git 忽略的 `.local/scroll-ui-qa/`。
