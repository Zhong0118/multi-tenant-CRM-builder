# 通用公共池本地验收与使用说明

日期：2026-10-14。范围：按业务表启用公共池、领取、手动释放、管理员分配、到期自动回收。仅本地开发和验收，未推送、未合并 main、未同步服务器。

## 使用步骤

1. 以公司管理员进入一张已发布业务表，点击右上角「公共池设置」。
2. 开启公共池；按需开启「到期自动回收」，填写保留小时数（1–8760）。保存立即生效，无需再次发布业务表。
3. 同一页面出现「我的记录 / 公共池 / 全部记录」。员工只有原权限允许的视图；OWN 员工没有「全部记录」。左侧仍是原来的业务表导航。
4. 管理员可以把已有未分配记录「释放」到公共池，也可以直接「分配」给本公司活动成员。启用开关本身不移动数据。
5. 有编辑权限的员工可以在公共池「领取」；领取前只能预览可见业务字段，不能编辑、上传附件、关联记录、跟进或执行工作流。
6. 员工在自己负责的记录上「释放」，确认后清空负责人和期限并移入公共池；其他成员可以再领取。管理员也可释放或重新分配。
7. 领取、专用「分配」操作按当前规则建立期限。业务内容编辑不会延长期限。后台每分钟检查一批到期记录，回收后进入公共池并记录系统审计，不需要有人打开页面。
8. 关闭公共池暂停领取、释放和回收，保留归属状态及已有期限；管理员仍可分配。重新开启后，过期记录恢复回收。

## 重要边界

- 各业务表独立配置，默认关闭；旧的负责人为空不等于公共池。
- 新设置的期限只作用于后续领取/分配，不给历史记录自动补到期时间，也不重算已有期限。
- 这是按时间回收的通用归属规则，不会自行猜测某个业务字段表示“已成交”或“已完成”。本轮没有新增按业务状态豁免、领取额度、审批或分池规则。
- 原有编辑表单或工作流若更换负责人，会清除旧负责人的期限；需要新的回收期限时使用「分配」。数据库触发器同时保证有负责人和公共池状态不能并存。
- 公共池不扩大其他成员私有记录或隐藏字段的访问范围。员工只读表可以预览公共池，但不能领取或释放。
- 自动回收每次最多 100 条，每分钟执行；停机期间到期记录在 API 恢复后的扫描中继续处理。不是精确到秒的提醒服务。

## 存储与服务

迁移 `0026_record_pool` 为 object_definitions 增加开关、期限规则和配置版本；records 增加公共池标记和归属到期时间。全部采用安全默认值，无历史记录回填。增加并发检查、约束、归属一致性触发器、回收索引及受限回收函数。

定时回收由 API 生命周期管理。数据库函数使用专用 NOLOGIN / NOBYPASSRLS 角色、固定 search_path 和受限策略；应用仅获得函数执行权，不需要管理员数据库凭据。

领取、释放、分配包含权限检查、活动成员检查、事务锁、版本检查和同事务审计。并发领取仅一个胜者；对不可读私有记录返回 404，避免通过冲突信息泄露其存在。
