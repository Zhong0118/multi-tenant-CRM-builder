# Excel / CSV 辅助新建业务表

## 使用流程

公司管理员进入 **设置 → 业务表 → 新建业务表**，填写名称和代码，在“从 Excel / CSV 生成字段”选择文件。

1. 支持 `.xlsx`、`.xls`、`.csv`；Excel 可选择工作表，CSV 自动识别编码并允许手动切换。第一行作为表头。
2. 核对每列的名称、建议类型和样例。可以取消不需要的列、修改类型、设置必填、编辑单选/多选选项。
3. 选择用于显示一条记录的标题字段。标题必须是文本、电话、邮箱或单选，且必填；其他字段是否必填由管理员决定。
4. 点击“创建业务表草稿”，一次性保存业务表及字段，进入设计器。
5. 在设计器配置员工权限、检查并发布。随后进入业务表 → 更多操作 → 导入 Excel / CSV，选择原文件导入数据。修改过列名或原文件有重复表头时，尤其要核对字段映射。

不上传文件时仍可手工创建空表。文件错误或尚未读完时禁止创建，避免误建空表；可以明确选择“移除文件，手工建表”。

## 自动识别范围

| 数据 | 建议 |
| --- | --- |
| 手机号、编号、前导零、长数字标识 | 文本，保留字符 |
| 全列一致的数字、金额、有效日期、兼容的日期时间、邮箱、是/否 | 对应类型 |
| 长文字、换行 | 长文本 |
| 状态、类别、标签等少量分类值 | 默认文本，提供可采纳的单选/多选建议 |
| 混合内容、空列、无法可靠判断 | 文本 |

判断检查整列非空值，不只看预览行。不根据“出现次数少”直接把人名设为单选，也不根据样例完整就自动设所有字段必填。名字不会自动绑定公司成员。权限、负责人和成员关系需要管理员明确配置。

复用现有解析器限制：文件 10 MB，所选工作表最多 10000 数据行、40 列；每个选择字段最多 100 个选项，每项最多 100 字。公式只读取已有缓存结果，不执行公式或宏。推断在浏览器完成，无需 AI API。

## 实现与修复

- 创建接口增加可选 `initialFields` 和 `titleFieldKey`，在租户事务内保存业务表、字段、默认列表、关闭的员工权限和审计。原空表接口行为保留，无新增数据库迁移。
- 创建仅保存结构草稿，不发布、不导入数据；字段默认对员工隐藏，在设计器确认权限后发布。
- 复核修复日期时间建议与后续导入转换不一致；不支持可靠转换的格式保留文本。
- 生成的选项键避开全部源选项标签，字段键避开全部源表头，避免后续导入把标签误识别成其他字段/选项的键。
- 真实浏览器暴露 DTO 未填写属性的 `undefined` 键引发错误校验；现与既有字段接口一致，先规范化 JSON 再校验和保存。新增实际 DTO 转换回归。
