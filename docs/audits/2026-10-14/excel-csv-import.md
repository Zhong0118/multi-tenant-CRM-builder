# Excel / CSV 导入完善与验收

## 交付范围

本地分支 `codex/csv-import-encoding-validation`。包含之前权限发布状态和 CSV 编码修复；本轮未推送、未合并、未部署，服务器仍不包含这些待同步改动。无需新增数据库迁移，复用 `record_import_rows`。

- 支持 CSV、XLSX、XLS；可选择工作表。Excel 解析器按需加载。
- 自动识别 UTF-8 / 带 BOM 的 UTF-16；严格 UTF-8 解码失败后尝试 GB18030，显示读取编码并保留手动选项。拒绝替代字符、明显二进制 CSV、列溢出、坏 Excel 文件。
- 保留编号前导零、手机号数字、日期；DATETIME 纯日期按既有 UTC 时间语义补午夜时间。公式使用文件中已有计算结果，不执行公式或宏；错误或未计算公式拒绝。
- 字段匹配优先字段 key，只有唯一名称才自动匹配；同名字段需手动选择，显示类型。重复映射、必填字段未映射阻止检查。
- 先检查后导入。检查复用服务端已发布字段、权限、选项和类型校验，不写记录、审计、编号或账本。实际导入再次校验。
- 可选 1–3 个已映射标量字段联合精确查重，空查重值报错。按当前成员可见数据查重，重复跳过，不覆盖、不暴露重复记录内容。
- 文件内跨批次重复：使用服务端规范化字段元组的 SHA-256 识别，支持金额、邮箱等规范化值。实际查重导入按租户/业务表事务锁串行，检查和创建同事务。
- 文件内容和工作表生成稳定批次 UUID，账本由租户/业务表/成员隔离；新增行和重复跳过行都记录账本。同文件重选即使没有重新选择查重字段，也不会新增已处理行。
- 浏览器自动顺序分批：最多 100 行且请求 JSON 小于 90 KiB；后端单请求仍最多 500 行。超长单行单独报错，不妨碍其他行。
- 显示检查/处理进度，网络失败停止后续请求并保留已完成结果。失败明细含源文件行号、原因、原始值，UTF-8 BOM CSV 并转义公式前缀。

## 使用方法

1. 业务表页面 → 更多操作 → **导入 Excel / CSV**。
2. 选择文件；Excel 选择目标工作表。检查前 3 行预览中的中文、手机号和日期。
3. 核对字段映射。同名字段选正确的字段类型；不需要的列选“跳过”。单选用已有选项名称，多选用分号分隔。
4. 若可能与现有数据重复，选择手机号、业务编号等能识别一条业务记录的查重字段。多个字段表示全部相同才重复，不要默认用姓名当唯一标识。
5. 点击 **检查数据**，查看可新增、预计跳过、错误数量。此时尚未写入数据；可修改映射/查重条件后重新检查。
6. 点击 **确认导入**。符合条件的行写入，错误行保留；查看最终成功/跳过/失败数量，可下载失败明细。
7. 网络中断后点击 **检查剩余行** 再继续。关闭页面后，用同一账号重新选择同一原文件和工作表恢复。关闭页面不取消已发送请求，但账本防止重试新增两次。

文件上限：10 MB，单个工作表 10000 数据行、40 列。500 是接口单请求限制，用户不再需要按 500 行手动拆表。超过文件上限需拆分工作表/文件，配合业务查重字段。

## 限制与待同步事项

- 自动识别编码不是数学上唯一确定；预览异常时手动切换编码或从原表另存为 XLSX。
- 已在服务器存成 `�` 的“手机号统计”历史记录不会自动恢复，仍需要未损坏原文件；本次不盲目删除或重复导入线上数据。
- 修改文件内容、工作表名称或更换账号会形成不同导入上下文，应重新选择业务查重字段。查重按可见范围，不是全局唯一约束；普通单条创建仍可产生业务重复。
- 页面关闭后不在后台自动跑剩余批次；恢复依赖重新选择原文件。导入开始后锁定编码、映射和工作表；失败内容需修正源文件再导入，并使用业务查重。
- 不支持通过名字绑定成员、不自动新增选择项、不覆盖已有记录。
- 本轮未验证生产 CI、镜像构建与服务器发布。上线应整合当前分支全部提交，包含前序权限修复，不要只部署旧的 CSV 修复提交。
