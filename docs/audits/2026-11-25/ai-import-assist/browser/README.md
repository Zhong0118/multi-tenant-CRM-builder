# 导入对照浏览器验收

赵晨以员工身份在本地星云科技演示公司的「客户」表上传两份合成 CSV。两张截图均通过 T3 无痕预览拍摄，视口为 1440 × 900 CSS 像素。浏览器连接实际 Nest API 和独立 PostgreSQL 库 `crm_pr2_browser_audit`。两次操作均停在检查数据前。

| 截图 | 文件与模型 | 浏览器结果 |
| --- | --- | --- |
| [批量留空](01-bulk-values-1440.png) | 合成等级表，23 行，未调用模型 | 「A级」由规则匹配。11 个不同的待核值各出现两次，员工先把「待核1」选为 B 级，按钮显示其余 10 个值、涉及 20 行。点击后出现「撤销本次批量留空」，撤销后再次显示 10 个值、20 行。 |
| [标题行下的 C1](02-header-c1-1440.png) | 合成交接表，3 行，本地模拟模型 | 首行为合成标题「客户交接清册（经办人：施迩澄）」。系统识别物理第 2 行为表头，模拟模型将第一列「采购单位名称」对到必填「客户名称」，第二列「客户等级」保留规则对照。 |

两份文件均为带 BOM 的 UTF-8 CSV。交接表的第二行是「采购单位名称,客户等级」，三条数据依次为「合成采购甲,A级」「合成采购乙,B级」「合成采购丙,C级」。等级表首行为「客户名称,客户等级」，第一条为「合成客户甲,A级」，后续为「合成0」至「合成21」，等级「待核1」至「待核11」循环两次。
