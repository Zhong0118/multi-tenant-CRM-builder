# 最终集可导入行数变化

h21–h30 在相同冻结标注的 95 条可导入行里，上轮命中 77 条，本轮命中 70 条。两次都采用了模型给出且符合标准答案的复核建议，并在剩余值全部应留空时使用批量留空。各文件的标注值、原件和分母相同。[上轮明细](../eval-final.md) · [本轮明细](eval-final.md)

| 文件 | 上轮 READY | 本轮 READY | 直接原因 |
| --- | ---: | ---: | --- |
| h22 | 3 | 0 | 模型将 Billing account name 高把握建议跳过，三行缺少必填的客户名称 |
| h23 | 4 | 0 | 客户等级取值的正确对照由 5/6 降至 0/6，四行未通过本地转换 |
| h24 | 4 | 10 | 正确取值对照由 4/10 增至 8/10，多六行能通过检查 |
| h26、h27 | 各 3 | 各 0 | 两份文件的正确等级取值对照均由 3/3 降至 0/3，各三行未通过本地转换 |
| 其他五份 | 合计 60 | 合计 60 | h28 命中 54 行，h29、h30 各命中 3 行，h21 和 h25 均为 0 |

造成最终集高把握错配率 1/44 的是 h22。该建议使记录在检查阶段因必填项缺失而失败。最终集所有实际 READY 行中，标注能够核对的非空值相对规则基线新增错值为 0。
