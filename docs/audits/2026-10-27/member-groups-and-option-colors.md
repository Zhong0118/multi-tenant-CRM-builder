# 成员小组与状态颜色验收

基于 main 2c50dfa，在独立工作树分支 codex/member-groups-and-option-colors 完成。本轮没有部署，没有修改生产配置或生产数据。

## 实现与边界

- 小组 CRUD、成员小组过滤、单组归属、可选组长、管理员逐表 GROUP 读取例外、原列权限和修改权限保留。
- 小组变动使用版本冲突校验，分组及成员变更遵循配置独占锁 → 公司成员锁 → 行锁，避免运行中的业务操作使用已变更的分组。
- 共用读取范围用于列表、计数、详情、导出、工作台、附件、关联、跟进、通知、AI、自动化和工作流。禁止 GROUP 修改范围及 GROUP 员工默认权限。
- 数据库迁移 0042 新增成员小组及可空 group_id，不为旧成员自动分组，不更新业务记录。小组有租户 RLS 和复合外键。
- 选项色板 8 → 12 色，历史配色保持稳定，保存/发布语义未变。

## 复核修复

1. 前端运行时 schema 解析器遗漏 GROUP，导致授权后页面打不开：扩展只读枚举，继续拒绝 GROUP 修改范围。
2. 表单把组长错误设为必填：允许有成员但暂无组长，停用成员可保留并清空组长。
3. 旧公共池缺少本组入口，私域视图硬编码 mine：添加本组范围，并保留私域阶段的组内可见性。
4. 组员负责人显示为“其他成员”：仅向有效 GROUP 返回组内 ID、姓名和状态，不返回手机号或公司完整成员目录。
5. 账号停用但成员行仍在职时，组内姓名目录错误显示在职：联合账号状态显示停用，记录仍可供组长交接。
