## 浏览器请求

浏览器记录了客户表相关 fetch 的方法、路径、状态、预览结果类型及视图保存范围。路径前缀为 `/api/v1/workspaces/nebula-demo/objects/customers`。

| 交互 | 实际请求与结果 |
| --- | --- |
| 生成三条草稿 | 一次 `POST /filter-preview` 返回 200，`kind=rule`。请求仅有 `text`、`currentRule`、`baseViewId` 三个顶层键。编辑和删除草稿都在本页完成。 |
| 应用 | 记录列表发出 `GET /records`，携带 `filters`、分页与排序参数，返回 200。此时浏览器尚未请求创建视图。 |
| 确认另存 | 一次 `POST /record-views` 返回 201，`scope=PERSONAL`。保存规则为 `stage in [proposal, negotiation]` 与 `amount gt 60000` 同时成立。 |
| 澄清与取消 | 同一预览端点返回 200，`kind=clarify`，两个选项均可见。选中选项和直接取消均未调用列表、视图或记录写入接口。 |
| 替换、追加、撤销 | 替换和追加各有一次预览请求，均返回 200。追加时的 `currentRule` 只有负责人条件。撤销与取消均未发起客户表请求。 |
