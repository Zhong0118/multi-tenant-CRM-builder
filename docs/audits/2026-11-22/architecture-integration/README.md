# 销售跟进与架构修复集成验收

基线为销售跟进 PR #82 的合并提交 7228fc4。浏览器以赵晨（员工）登录隔离的本地演示库副本，从客户表进入实际详情路由。本轮复测了列表拆分和旧抽屉移除后受影响的操作。

| 操作 | 浏览器观察 |
| --- | --- |
| [进入客户表](01-records.png) | 「全部（按权限）」显示 6 条客户记录。 |
| [选择客户并打开视图菜单](02-select-and-switch.png) | 勾选「启明工贸」后出现批量操作栏。 |
| [切到「我负责的」](03-switched-view.png) | 仍能看到「启明工贸」，当前页有 6 条记录，勾选数为 0，旧批量操作栏收起。 |
| [从名称打开详情](04-detail.png) | 进入「启明工贸 #20」详情页，保留「整理本次沟通」入口。 |

该流程只读取演示数据。迁移和 E2E 使用独立数据库。其余产品流程的销售跟进基线截图见[主线验收](../sales-followup-main/)。
