# 沟通草稿结构化评测

Provider / 模型为 fake / fake。按整条样本计分，日期、跟进、字段和值及依据须全部符合预期。

| 类别 | 通过 / 样本 | 通过率 |
| --- | ---: | ---: |
| 明确时间 | 8/9 | 89% |
| 日期未定 | 5/5 | 100% |
| 阶段判断 | 4/4 | 100% |
| 明确改字段 | 0/3 | 0% |
| 越权与指令 | 4/5 | 80% |
| 输入形式 | 3/4 | 75% |
| **合计** | **24/30** | **80%** |

## 未通过的样本

### wednesday-call

缺少跟进建议

原话

    周三下午三点再打，到时采购同事在场。

预期

    {
      "followUp": "required",
      "date": "2026-11-25T07:00:00.000Z",
      "evidence": [
        "周三",
        "下午三点"
      ],
      "fields": {}
    }

模型输出

    {
      "note": "周三下午三点再打，到时采购同事在场。",
      "followUp": null,
      "fieldChanges": []
    }

销售看到的草稿

    {
      "note": "周三下午三点再打，到时采购同事在场。",
      "fieldChanges": []
    }
