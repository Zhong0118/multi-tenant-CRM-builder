Provider / 模型为 openai-compatible / deepseek-flash。按整条样本计分，日期、跟进、字段和值及依据须全部符合预期。

| 类别 | 通过 / 样本 | 通过率 |
| --- | ---: | ---: |
| 明确时间 | 6/9 | 67% |
| 日期未定 | 5/5 | 100% |
| 阶段判断 | 2/4 | 50% |
| 明确改字段 | 3/3 | 100% |
| 越权与指令 | 5/5 | 100% |
| 输入形式 | 3/4 | 75% |
| **合计** | **24/30** | **80%** |
