# 业务表批量删除

本地分支 `codex/record-bulk-delete` 基于 PR #61 的 `a6a7cda`，本轮未修改该 PR、未同步服务器。

## 使用

1. 管理员进入业务表，按需要筛选记录。
2. 右下角选择每页 20、50、100、300、500 或 1000 条。
3. 勾选需要删除的记录，或勾选表头选择当前页。
4. 在底部操作栏点击“批量删除”，核对数量后确认。
5. 查看成功、失败数量。临时失败可以重试失败项；版本冲突需关闭、刷新并重新选择。

支持任意 1–1000 条，不要求选满 20 条。翻页或切换筛选会清除勾选，不隐式选中其他页。删除权限沿用现有管理员规则；没有删除权限的用户不显示入口，API 仍独立校验。

## 实现边界

复用现有版本化单条软删除接口，以 4 并发队列处理，不新增后端接口或数据库迁移。每条独立提交并留审计；版本冲突不强删，404 不当作已确认删除。成功项不会重试；离开页面后停止派发新请求，已经提交的请求仍可能完成。

删除结果与刷新错误分开显示。刷新前取消同查询的旧请求，防止慢响应恢复已删记录；显式读取并更新缓存，避免离线查询暂停锁住面板。关闭结果面板时回退到有效页码，保留原搜索、筛选与排序。

- 浏览器在独立数据库新增 1001 条专用数据，当前页选择 1000 条，成功删除 1000 条；未选中的第 1001 条仍存在。
