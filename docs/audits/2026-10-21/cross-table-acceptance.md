## 交付范围

- 管理员配置手动确认或字段变更触发；目标表、来源字段/固定值/当前时间/执行时补填、负责人、角色和启停。
- 公司关系总览、可点击规则连线、字段对应界面、无写入样例预览、草稿与当前生效分离，发布后启用。
- 员工预览/确认、结果入口、失败反馈、同一请求重试、成功历史和双向记录关联。每位执行人仍受原有记录范围和字段权限限制。
- 复用现有 CREATE_RECORD / CREATE_RELATION 动作引擎与记录命令，单次执行事务提交；普通编辑、批量编辑、AI 确认走同一触发判断。新建、导入、历史数据不补跑，自动化不递归。
- 0036 迁移仅新增执行历史及其租户隔离/不可变约束，不转换既有业务记录。这里只应用到专用测试和演示库。

## 边界与限制

- 首版是“创建时复制 + 记录关联”，不是实时引用、汇总或任意脚本流程图。历史成功不因规则修改重跑。
- 失败在界面与公司安全审计中呈现；当前成功历史最多100条，没有独立失败队列或后台自动重试。
- 员工 MEMBER INPUT 不能发布，建议复制来源成员/管理员固定成员；管理员专用动作仍支持临时选择成员。成员有效性在运行时检查。
- 本轮未宣称全仓 lint 通过；API 原有无关 lint 问题仍存在，详见本地工作报告。
- 浏览器开发环境未配置独立流程状态的表，旧 workflow endpoint 会返回已被界面处理的409；没有把这一既有响应当成本功能成功或失败的证据。
- 未调用真实短信/真实AI提供方，未进行生产部署或线上公司流程验收。
