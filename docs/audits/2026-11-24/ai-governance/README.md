## 字节估算与 DeepSeek 实报

使用 deepseek-flash，对四个生产 provider 方法各发中英文合成输入。两轮助手各调用一次只读工具并收到工具结果，共 8 个输入、10 次物理请求。采样脚本在内存接收计量回执，数据库写入另由 PostgreSQL 集成测试验证。没有使用客户数据。

输入预估等于最终 JSON 的 UTF-8 字节数加每条消息 16 token。下表只比较输入。准入时另加该功能的完整输出上限，有回执后按实际输入和输出结算。

10/10 次估算覆盖实报。预估输入合计 38,134 token，实报输入 11,457 token，倍率 3.33。单次倍率 1.73–3.63。低估 0 次，最大低估 0 token。实报输出 3,781 token，共结算口径 15,238 token。最终样本中缺失回执、使用估算结算、失败和取消均为 0。

首次联调时，整理沟通的两条样本均返回 HTTP 400，没有 usage。原因是日期的 JSON Schema 把时间选项嵌套在 anyOf 中。展平结构、保留合法输入并通过回归测试后，重跑全部四个入口。上表只统计修复后的完整一轮。

## 管理页面与使用者验收

本地独立 PostgreSQL 18 数据库与 Redis，API 使用模拟 provider。演示租户为「星云科技演示公司」，以刘洋、赵晨、孙悦及独立平台管理员登录。套餐切换、拦截与权限检查使用真实 HTTP 会话。额度边界通过隔离数据中的预占及结算函数构造。真实 DeepSeek 的用量结果见上文。

| 场景 | 证据和结果 |
| --- | --- |
| 1 · 默认套餐 | 默认配置返回全部五项。赵晨发出助手消息并生成修改阶段提议。对跟单商机的金额筛选返回规则。刘洋整理沟通返回 READY，建表返回 blueprint。迁移已有公司的回填由数据库升级测试覆盖。 |
| 2 · 基础版 | 分配只含助手和筛选的套餐。赵晨列表的「整理沟通」入口消失。刘洋的业务表设置隐藏建表入口，从原地址进入显示套餐缺失。两人调用整理沟通均返回 403。建表接口对刘洋返回套餐 403，对赵晨返回角色 403。刘洋设置页列出全部五项，三项显示缺失。基础助手能回答，降级前的提议确认被拒绝。 |
| 3 · 更换立即生效 | 平台在独立会话中换回含全部功能的套餐。在赵晨原登录会话重新加载客户列表，四个行内与操作列「整理沟通」按钮恢复。 |
| 4 · 统计 | 赵晨多次调用。刘洋可见成员用量、对话助手分布和提议数。平台公司详情只提供公司级数字。 |
| 5 · 公司额度耗尽 | 实际用量达到 80% 时员工输入区显示 80% 提示。100% 时再次发问收到 AI_TENANT_QUOTA_EXHAUSTED，恢复日期为 12 月 1 日，拒绝前后成功调用数均为 8。历史可读，原提议确认后变为 EXECUTED。刘洋的通知接口分别返回一次 AI_QUOTA_80 和 AI_QUOTA_100。 |
| 6 · 本月加量 | 平台加 5 万 token，赵晨在原会话中再次发问成功。用独立空公司给本月追加 10 万 token，将该笔结算月份与加量明细一起置为上月，重新读取本月汇总，额度从 1010 万回到套餐的 1000 万 token，本月加量为 0。此项使用账期夹具。 |
| 7 · 人均分 | 刘洋切换时，确认框列出 10 位在职成员、每人份额和超额人数。月额度 20 万 token 时，孙悦用完 2 万 token 后被个人额度拦截，助手提示 12 月 1 日恢复，赵晨仍可发送。隔离夹具停用一名成员后，份额从 20,000 变为 22,222，再恢复成员。 |
| 8 · 紧急关闭 | 平台关闭后，赵晨助手收到 AI_PLATFORM_DISABLED，同一会话的客户列表接口仍为 200。平台恢复后可以继续生成。 |
| 9 · 并发 | PostgreSQL 实际角色并发预占、结算、重放和加量复用本报告的数据库测试。两个偏差合计 340 token，只结算一次。 |
| 10 · 取消 | 在隔离 API 进程中仅给指定验收文案的 fake 建表方法增加可取消延时。刘洋点「生成预览」再点「取消生成」。真实 HTTP 取消穿过计量层，数据库状态为 cancelled，输入 553、输出 16,000 token 均标估算。 |
| 11 · 操作记录 | 按赵晨和改记录筛选得到 1 条提议。点击已确认行，可读提问原文、确认人、商机阶段原值和新值，以及指向实际商机的链接。员工从设置地址进入显示权限兜底，操作记录接口返回 403。 |
| 12 · 隔离 | 刘洋读取第二家公司设置、操作记录和尝试创建平台套餐均为 403。员工读取平台套餐也为 403。另有受限角色数据库与 HTTP 集成测试。 |
| 13 · 审计 | 隔离库实际产生套餐创建、编辑、公司分配、本月加量、紧急关闭与恢复、分配方式修改六类审计事件，均带操作者和修改后值。设置前后值与业务事务由治理 API E2E 核对。 |
| 14 · 布局 | 平台两页 1440/1280，公司设置 1440/390，以及零用量和额度耗尽均完成截图。390 与 1280 宽页面实测文档宽度与视口一致。平台套餐初次加载曾触发关闭的抽屉 hydration 警告，修正后再次硬刷新、打开编辑抽屉并重拍通过。 |
