# 员工核对采购回访表

赵晨以员工身份，在星云科技演示公司的「客户」表导入两行合成采购回访。T3 无痕预览的视口为 1440 × 900 CSS 像素，PNG 以两倍分辨率保存。两张截图来自同一次生成，使用本地模拟模型、真实 Nest API 和专用 PostgreSQL 库 `crm_pr2_browser_audit`。

| 步骤 | 页面结果 |
| --- | --- |
| [AI 返回建议](01-employee-suggestions-1440.png) | 上传后原有三列均待处理。员工点「AI 帮我对列」，系统预选「采购单位名称 → 客户名称」和「客户级别 → 客户等级」。「走访纪要」仍显示跳过，旁边有低把握建议和「采用」按钮。 |
| [员工采用并检查](02-employee-adopted-1440.png) | 员工采用「走访纪要 → 追加到客户备注」，顶部显示「已完成对照」，三列均保留 AI 建议标签。检查结果为可导入 2、重复或已导入 0、主动跳过 0、错误 0。 |

两次演练各调用一次模拟模型、执行一次数据检查，均停在「确认导入」前。业务记录数在首次演练前和复拍后均为 107。

复跑文件名为 `华东采购回访.csv`，使用带 BOM 的 UTF-8、LF 换行和末尾换行。SHA-256 为 `a217763aabdf44a8f202fc4ed58e56984b179cffb37e393963e7244ec272288d`。
