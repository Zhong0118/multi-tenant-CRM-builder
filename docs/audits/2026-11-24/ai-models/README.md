- PostgreSQL 18 的全套 API E2E 451/451，数据库集成 110/110。初跑用 PostgreSQL 15 缺少既有日期筛选所需的函数，最终验收使用与项目部署同主版本的独立库。

- 迁移 0055 新建供应商、密文、模型、修订、测试及用途分配；0056 引入功能目录与授权约束；0057 为账本增加调用配置和单价快照。旧账本无法补全的历史价格显示为未知。
