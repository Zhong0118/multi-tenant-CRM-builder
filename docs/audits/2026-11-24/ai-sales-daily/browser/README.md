## 功能与数据库结果

| 场景 | 实测结果 |
| --- | --- |
| B10 权益与个人范围 | 原套餐未含三项 B 权益。三人均可 GET 清单，每人分别直调三项生成均返回 403，调用账本维持 0。赵晨四组依次为逾期 2、将收回 1、停滞 1、久未联系 22。两个逾期项包括同事负责但赵晨可读且本人应跟进的客户。刘洋只看到自己的 1 条久未联系，孙悦也只看到自己的 1 条。另以钱宇验证四组均为空，生成按钮停用，直接请求也仅返回空列表，账本维持 17 次。 |
| B11 归组、排序和设置 | 重叠记录「远山科技」同时命中逾期、即将收回和久未联系，仅入逾期组。「云桥制造」2 天后收回，「云桥报价项目」在方案报价停留 15 天，已成交记录不入四组。久未联系 22 条，首屏 5 条，抽屉首批 20，点击加载后显示 22，HTTP 游标两页的 ID 去重仍为 22。刘洋无 B 权益时将久未联系阈值由 14 调至 28 天，赵晨重新读取该组由 22 变成 0。 |
| B12 缓存、并发、日切 | 连续三次读取建议，账本总数保持 3。孙悦首次并发两次生成，模型调用增加 1。三次重生成剩余依次为 2、1、0，第四次返回 429，账本仍为 7。将测试租户从上海切到当时仍是 11 月 23 日的檀香山，新日期显示尚未生成、可再生成 3 次，随后恢复上海时区。 |
| B13 详情与人工确认 | 赵晨生成报价微信，实际响应含 `【报价金额】`。点「已发送，记一笔沟通」打开原表单，默认微信/消息，取消后该记录活动为 0，保存一次后为 1。建议进入原跟进表单时标题为「致电确认近况」，日期为空。收起后跟进总数仍为 3，手工补时间并提交后为 4。另用模拟提供方将同一记录建议日期设为 2026-11-27，真实接口返回此日，从工作台打开的原表单预填 `2026-11-27T09:00`。只开通写作时，独立抽屉显示「远山科技 · 帮我写」。 |
| B14 聊天写作和字段权限 | 客户列表中输入「给远山科技写条微信」，助手先列出记录编号 10001 和 10006，选择 10001 后显示该客户写作卡。该确认回合的写作和助手各产生一条账本记录。为客户备注设置成员级隐藏并植入唯一测试串，运行时在 fake provider 边界观测结构化输入和原始响应，同时核对 HTTP 输出。今日建议、详情写作、日报及聊天嵌套写作四次检查均未出现测试串。 |
| B15 日报 | 今日事实来自本人登记的两次沟通，次日待办来自「明日确认回访」。计划和问题无依据而留空。选择完成情况追加、明日安排替换，浏览器表单分别保留原文和替换成功；此时读取服务端日报仍为空。另一客户端先存版本 1，原页面提交收到 409 并保留本地修改。未来一天及早于七天的日期返回 400，往前第七天可请求。 |
| B16 计量 | 对照公司 `/ai/usage`、平台该公司 `/platform/tenants/:id/ai` 和 `ai_model_calls` 聚合，调用数与输入/输出 token 逐项相等。对账时 assistant 为 2 / 7859 / 4108，daily_brief 为 7 / 56 / 84，writing 为 6 / 48 / 72，daily_report 为 4 / 32 / 48。此处为模拟提供方测试账本。 |
| B17 页面 | 上表 13 种页面状态均实测两种目标宽度。日报预览并排显示已有内容和 AI 草稿。将浏览器切为 UTC 时，本地为 08 时，写作和日报分别展示上海公司的 16:57:21 和 16:57:24。 |
