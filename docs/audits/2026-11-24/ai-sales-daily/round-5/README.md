## 写作截断

## 销售试用

- 今日建议和写作共用单选值的名称解析。模型输入和展示的依据使用「方案报价」。说明只重复标题时收起；有可处理的逾期跟进时，打开原跟进。
- 收到员工明确要求询问的事项后，写作预览以「本次补充」为来源。邮件核对主题和正文，拜访提纲优先列对应问题。远山科技的实测提纲分别询问交期与样品，保留拜访入口。邮件仍可能生成需要人工填写的占位符。
- 拜访准备仅保留复制、重新生成。其他写作登记沟通时，编辑框统计未填占位符，全部填完才可保存。
- 日报从获准查看的沟通中提取完整短句、沟通类型及已登记结果，按「记录名：动作，结果」输出一行。含占位符的句子被排除。过长且无法安全摘引时，仅采用已知的沟通类型、结果。今日建议同样压缩沟通依据。
