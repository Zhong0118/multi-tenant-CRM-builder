# 业务表快捷问题和合同开发样本

赵晨在本机星云科技演示公司分别打开客户和合同详情。面板显示「查看客户概况」和「查看合同概况」。移除页面关联后，在没有可用表名的面板里显示「我能查看哪些业务表」。本次浏览器检查只查看快捷问题，未发送消息或确认写入。[客户详情](record.png) · [合同详情](contract.png) · [解除页面关联](unbound.png)

DeepSeek Flash 完整跑了一次扩充后的开发集，严格评分 **33/35**。本轮未重跑冻结留出集。四条合同样本均走筛选预览并生成规则，严格通过 **3/4**。[逐例原始输出](../assistant-v2-final-review/assistant-contracts-development.md)

| 合同筛选请求 | 实测 |
| --- | --- |
| 本月签约 | 签约日期使用相对范围 `this_month` |
| 标签包含续约或框架 | 正确选择两个多选键。唯一的 `in` 条件外层用了 `any`，标注为 `all`。当前命中集合相同，但用户再追加条件时可能不同，保留严格失分 |
| 法务经办人是我 | 引用自定义成员字段与 `$me` |
| 法务经办人是我且 12 月签约 | 以「且」组合成员条件和 12 月 1 日至 31 日的日期区间 |

另一条失分来自原有沟通样本。用户选择「只记录沟通要点」后，模型再次询问输入方式。这次真实运行保留了两项差异。模拟链路严格开发集为 35/35。关联字段未在本次模型评测覆盖。
