复测前的三个手填替代字段问题（自动含税费用、关联客户、自动毛利）均在对应的数据集通过。服务端另用历史输出回归了同名字段和公式中的正常输入字段。预览中的全部权限都保持为意图或推荐。三种伪造授权的请求均在进入持久化前被拒绝。

中途增加了可展示的权限推荐枚举。第一轮开发集为 **19/20**，其中七表调用不可用。增加枚举后，一次独立乐团试调用在 0.3 秒内被拒。将模型输出的推荐项调整为必传、允许 null 后，该业务生成成功，耗时 18.9 秒，表编码为 `rehearsal-sessions`、日期字段键为 `rehearsal_date`，推荐为「可新建，只看改本人」。随后在该契约上完整重跑开发集，报告采用后一次分数。留出集真实调用发生在新增推荐枚举前。对其原始结果仅补空推荐值，使用最终校验逻辑离线回放，仍为 9/10。最终推荐枚举在留出集上的模型生成效果未验证。

对开发集两次失败另做单例诊断。面试表在 14.3 秒生成成功。七表在 60.4 秒返回全部七个名称，出现「一次最多创建 6 张，请移除 1 张」。单例结果不计回整组分数。原 HTTP 接口限时 60 秒，会丢弃后一份有效结果。当前接口和评测统一使用 90 秒，预览和调整可随时取消。供应商偶发不可用仍可能需要管理员手动重试。

## 本地功能与验证

- 管理员可编辑模型建议的表编码和字段键，确认时复查最新元数据。已有表补字段时保持原表编码。
- 超限候选支持取消勾选和重新勾选。重名提示显示在对应表。被移至未采纳清单的替代字段，须由管理员点击「作为手填字段添加」。
- 员工权限初始选择「暂不开放」。可单独采用推荐或手动选预设。每表列明前后差异；新建权限与草稿及审计一起提交。选择暂不开放可以保存草稿，发布分析仍会指出必填标题对员工隐藏。补字段保持原表权限。
- 删除 `unicode-case-folding` 依赖；批量建草稿、分析和整组发布迁入 `ObjectDraftBatchService`。手动和批量操作复用现有事务方法。
- 类型检查、API 构建通过。API 单元 1957/1957，Web 单元 1393/1393、架构 3/3，HTTP E2E 440/440，数据库集成 97/97，建表评测自测 5/5。HTTP E2E 覆盖了跨租户拒绝、权限随发布生效、可编辑标识持久化和第三表失败时整组回滚。
- 本地模拟服务用管理员会话请求「只建合同表，需要自动计算毛利。销售只能看自己的记录。」返回 HTTP 200。只生成预览，核对了表编码 `rental-contracts`、可选手填字段 `gross_profit` 和权限推荐 `CREATE_OWN`。
