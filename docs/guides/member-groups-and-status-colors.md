# 成员小组、组长权限与状态颜色

## 管理员设置小组

1. 进入公司设置 → 成员 → 小组，点击「新建小组」。
2. 输入名称，选择员工；可指定一位组长，也可先不指定。每位员工最多一个小组。
3. 保存后立即生效，不需要发布业务表。员工移入新组会退出原组，记录仍归原来的员工负责；其他组的组长需要先在原组替换，才能移入。
4. 列表中点击「组长权限」，展开要授权的业务表，点击「设置表例外」。
5. 开启「可以查看记录」，将「查看范围」设为「本组成员名下」。检查新建和修改权限，通常保持「修改范围：仅本人负责」，然后「保存例外」。
6. 每张业务表分别授权。设置列权限时，原有隐藏和只读仍有效；分组不绕过列权限。

组长仍是员工，不能管理小组或自行增加权限。这里新增的是读取范围，没有新增“本组修改”选项。能否编辑仍取决于原来的修改权限，并受可读范围限制。

## 员工和组长怎样使用

普通员工的权限不因为加入小组而扩大。组长只有在获准的业务表中能看到自己和组员负责的记录；负责人列和详情会显示组员姓名。列表、详情、搜索、导出、工作台和 AI 查询使用相同范围。

开启旧版公共池的表可以切换「本组记录」。启用分阶段公海的表，待联系、跟进中、受保护等视图按获准范围显示组内记录。公共池继续按已有公共池规则开放；未指定负责人且没有进入公共池的旧记录，不会因此自动可见。

组员调组后，记录负责人不变，组长可见范围跟随最新分组。停用成员仍留在原组时，其待交接记录可以由在职组长查看。

取消组长或解散小组后，原组长保存的「本组」读取例外降为「仅本人负责」；解散不删除员工和业务记录。原逐表例外仍保存，日后再次指定该员工作为组长时会按其当前小组生效；不希望保留时请在访问权限中恢复默认或另设范围。

## 如何修改状态颜色

公司设置 → 业务表 → 对应业务表 → 字段与表单 → 配置单选/多选字段，在选项的颜色中选择，保存后发布业务表。

可选 12 色：灰、蓝、青、绿、黄、橙、红、紫、粉、靛蓝、青绿、棕。它是预设色板，不是随机配色；没有指定颜色的旧选项仍按原来的颜色循环显示，已保存的颜色不会变化。改色后先保存草稿，再发布，员工端刷新后生效。

## 跟进是否自动生成询单

本轮只读核实的线上「通过表」和「询单表」没有发布跨表自动化规则，因此填写「跟进事项」只会安排待办；完成待办、填写结果也不会自动新增询单。

客户明确提出需求或询价后，可在询单表手动新建。若希望减少重复填写，可以由管理员使用已有的通用跨表自动化，配置明确的「生成询单」动作及字段映射。是否填写过跟进内容本身不足以判断是否应该生成询单。本轮没有替公司新增或修改这类规则。
