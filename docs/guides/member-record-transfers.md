# 控制员工导入和下载业务表数据

例如，要让员工能看客户、能逐条新建客户，但不能导入名单或下载客户清单：

1. 公司管理员进入「公司设置 → 业务表」，打开客户表的「员工权限」。
2. 保留「新建记录」「查看记录」，关闭「导入记录」和「下载数据（导出）」。这两项互相独立，也可以只关其中一项。
3. 点「保存员工权限」，对照「当前生效」和「已保存草稿」，检查并发布。发布应用这张表全部已保存的修改。
4. 如果只限制一名员工，在「公司设置 → 成员」找到此人，点「查看和设置」，展开客户表，设置成员例外并保存。成员例外立即生效，无需发版或重新登录。多选员工时，导入和下载可分别选「保留各成员设置」「允许」或「禁止」。
5. 用员工账号刷新客户表，在「更多操作」核对「导入 Excel / CSV」「导出当前结果」。两项都禁止且没有其他操作时，页面不显示这个菜单。

旧表未配置时保持原行为：有查看和新建权限的员工可以导入；有查看权限的员工可以下载当前可见数据。设置成员例外不会影响同事，组长也受这些开关限制。导出仍遵守负责人、分组和隐藏列规则；导入仍遵守可写字段限制。这里的「下载」指业务表记录导出，不包括记录附件。已经下载的文件不会因撤权而被收回。
