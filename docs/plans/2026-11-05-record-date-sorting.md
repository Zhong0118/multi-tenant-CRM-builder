# 业务日期排序与筛选

目标：晚导入的早期业务日期仍按业务日期排位；支持快捷日期和范围筛选；保留现有公司数据、权限与其他工作树。

已验证：线上询单表 col_2 为 TEXT，默认 createdAt desc；点文本排序无法正确排序混合格式。现有日期过滤按字符串比较，日期边界未验证有效日历；默认视图只允许系统字段。

设计：
1. 默认视图可选启用的可排序业务字段；员工不可查询排序列时回退 updatedAt，禁止借排序泄露隐藏字段。
2. TEXT 字段可由管理员开启 config.dateInterpretation=true，按年/月/日解释排序和范围筛选，原值保留；两位年份明确解释为 2000–2099。未识别和空值置后；不猜测无年份日期。
3. DATE/DATETIME 过滤走类型化 SQL，严格验证日历、日期时间与时区。相对日期以公司时区为准；结束日期包含整天。
4. 导入支持完整年及明确两位年的点/斜线/横线日期；修正无效日期自动滚动风险。新建表日期识别复用现有日期解析，不新增依赖。
5. 范围筛选复用 Ant Design RangePicker，补充昨天/上月，保留 URL、已保存视图及权限约束。

执行：默认视图与字段配置；导入日期识别；运行时排序过滤及 UI；整体验证和独立复核。
不修改生产数据/配置，不部署。上线后管理员选择日期识别和默认排序并发布，现有个人筛选视图仍优先。
