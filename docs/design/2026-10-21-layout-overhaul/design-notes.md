# 版式重做 · 第 01 轮（2026-10-21）

上一轮（`docs/design/2026-10-20-ui-direction/`）定下的是风格 D：青绿 `#0E7C6B`、浅灰侧栏、发丝线表格。用户反馈「看起来和之前没区别」：改动停在颜色、边框和字号，各页面的骨架——左上角有什么、按钮在哪、筛选怎么出、详情怎么排、管理页怎么填——基本没动。这一轮风格不变，只重做版式。

## 用户点名的问题

1. 消息铃铛单独漂着，位置尴尬。
2. 列表不能拖拽调整列宽。
3. 「更多筛选」点开后把剩余条件全部铺在表格上方。
4. 查看 / 编辑的详情没有像样的设计。
5. 成员管理、公司审计、设置：很大很空，不直观。
6. 管理业务表：内容宽度不统一（有的全宽，有的半宽），很多地方还是最初的风格。
7. 要按页面类型分别提升美观、可用、可操作；参考成熟产品；按 oil-ui 的流程走。

## 第 02 轮：用户的选择（2026-10-21）

四项都选了推荐方案。风格（青绿 `#0E7C6B`、浅灰侧栏、发丝线表格、分段控件）沿用 D，不再动颜色。

| 决定 | 内容 | 依据 |
| --- | --- | --- |
| 消息 | 「消息 N」是侧栏「工作」组的一项，和跟进待办并列；点开从侧栏右侧滑出 420px 面板。「收起菜单」改成左上角公司行末尾的图标，底部只留账号块 | Linear 收件箱、Notion Inbox |
| 列表 | 页头行（对象名 + 条数 ｜ 导入/导出 ▾、＋新建）→ 视图行（我的/公共池/全部 + 保存的视图，同一排标签 ｜ 搜索、列、⋯）→ 条件行（常用字段下拉 + 已用条件小块 + ＋筛选浮层 ｜ 清除 · 保存为视图）→ 可拖宽的表格 → 页脚（条数 ｜ 每页、分页）；勾选后底部浮出批量操作条 | HubSpot 视图标签与常驻快捷筛选、Attio/飞书条件浮层、Attio 批量条 |
| 详情 | 整页两栏：顶部面包屑「‹ 客户 / 名称」与「‹ 3/17 ›」；左栏 360px 身份、归属、操作、字段（编辑在左栏进行）；右栏带数量的标签页，「概览」放下一步跟进、负责人、最近动态、关联记录 | Attio 记录页 |
| 管理页 | 侧栏「管理」组收成「设置」一个入口；进入设置后侧栏换成设置导航（‹ 返回工作区 / 成员与权限 / 数据 / 安全）；列表页 ≤1200px，表单页 720px，居中 | Linear、Attio 设置区 |

## 第 03 轮：结构重做的落地规则（2026-10-21 晚）

第 02 轮只落了外壳（侧栏消息、设置区导航）和几个未接线的零件（`Page`、条件浮层、列宽拖拽、审计句子化接口）。这一轮把每类页面的骨架按下面的规则重排，现有结构不当作约束；功能全部保留，只换位置。

### 宽度只有两种

| 区域 | 宽度 | 页面 |
| --- | --- | --- |
| 工作区 | 满宽，左右 24px | 业务表列表、记录页、跟进待办、工作台、统计、AI |
| 设置区 | 一列 1040px 居中 | 设置首页、成员、成员权限、审计、业务表、业务表设计器（含字段双栏）、关系与自动化、工作台配置 |

设置区里的表单不再另开 720px 窄列：用「左标签 220px / 右控件」的行铺满同一列，所以标题、工具行、表格、表单的左右边缘在所有设置页上对齐。

### 页面语法（所有页面一致）

1. 页头一行：标题 20px + 灰色数量 + 状态；右侧次要按钮在前、主按钮最后；说明最多一句，能删就删。
2. 工具行：左搜索与筛选，右视图类工具；批量操作不常驻，勾选后从底部浮出。
3. 内容：表格不再套卡片面板；行操作统一收进行尾「⋯」。
4. 浮层：短表单 Modal 520；带预览或长表单 Drawer 560/720，底部固定操作栏；需要整页参照的（记录详情）用整页。

### 记录列表（核心页）

页头（图标 + 对象名 + 条数 ｜ ⋯ 导入/导出/公共池设置、＋新建）→ 视图行（范围分段 + 我的视图 ｜ 搜索、列）→ 条件行（常用下拉 + 已用条件块 + ＋筛选浮层 ｜ 清除 · 保存为视图）→ 可拖宽表格 → 页脚（条数 ｜ 每页、分页）。「更多筛选」整行铺开、「更多操作」里混放批量与导出、常驻的分页信息全部拆掉。

### 记录页

取消「列表 40% + 详情 60%」的并排：列表被压到截断、详情被压成三栏。改为整页：顶栏面包屑「‹ 客户 / 名称 #3」+「‹ 3/17 ›」逐条翻看 + 编辑、⋯；左栏 360px 是身份与属性（归属与流转、字段只列一次），编辑在左栏就地进行；右栏是带数量的标签页。

### 设置首页

卡片拼盘改成分组的行列表（图标、标题、一句说明、当前值 ›），与侧栏设置导航一一对应。

### 第 03 轮落地结果（2026-10-21 晚）

| 区域 | 落地 |
| --- | --- |
| 共享件 | `Page` 宽度收成 `full / settings(1040) / form(720) / bleed`；新增 `SettingRow`/`SettingRows`（左标签 220 / 右控件）；`OVERLAY_SIZE`（确认 440、短表单 520、窄抽屉 480、抽屉 560、宽抽屉 720）；抽屉操作统一进底部固定栏；主区细滚动条、透明轨道，不再盖住面板圆角；`scrollbar-gutter: stable` 防止页头跳动 |

| 记录列表 | 页头（图标 + 名称 + 条数 ｜ ⋯ 导入/导出/公共池设置、＋新建）→ 视图行（范围 + 我的视图 ｜ 搜索、列）→ 条件行（常用下拉 + 条件块 + 筛选浮层 ｜ 清除 · 保存为视图）→ 可拖宽表格 → 粘底页脚；勾选后页脚变为批量操作条 |
