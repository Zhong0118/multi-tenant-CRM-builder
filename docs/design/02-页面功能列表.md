# 页面功能列表

## 1. 路由与访问约定

- 平台后台使用 `/platform/*`，只允许平台管理员访问。
- 独立用户使用 `/waiting` 和 `/invitations/[invitationId]`，只能访问本人账号和邀请，不能访问任何租户业务数据。
- 租户工作区使用 `/workspace/[tenantCode]/*`；`tenantCode` 只定位工作空间，服务端必须验证当前用户的成员关系，不把 URL 或客户端提供的 `tenant_id` 当授权依据。
- 首家公司业务对象使用稳定业务路由；其他动态对象使用 `/workspace/[tenantCode]/objects/[objectCode]`。
- 页面 URL 保存分页、搜索、筛选、排序和视图标识，刷新与分享后可恢复工作状态。

| `/login` | 登录 | 全部人类用户 | P0 | 手机号+密码；错误次数限制；注册和忘记密码入口 |

| `/invitations/[invitationId]` | 接受租户邀请 | 受邀用户 | P0 | 公司、角色和邀请人摘要；接受或拒绝；校验本人手机号 |

## 3. 平台管理后台

### 3.1 平台总览

| 路由 | 页面 | P | 核心功能 |
|---|---|---|---|
| `/platform` | 平台总览 | P1 | 租户数、活跃成员、记录量、导入任务、错误趋势；进入异常租户 |

总览只展示平台运行数据，默认不聚合租户业务金额，避免平台管理员无必要接触客户业务数据。

### 3.2 租户管理

| 路由 | 页面 | P | 核心功能 |
|---|---|---|---|
| `/platform/tenants` | 租户列表 | P0 | 搜索、状态筛选、新建、停用、查看配置完成度 |
| `/platform/tenants/new` | 创建租户 | P0 | 基本信息、工作空间代码、模板、首位管理员手机号邀请、确认创建 |
| `/platform/tenants/[tenantId]` | 租户概览 | P0 | 基本信息、状态、成员数、记录量、模块、最近变更 |
| `/platform/tenants/[tenantId]/configuration` | 租户配置 | P0 | 对象、字段、视图、状态和导航排序 |
| `/platform/tenants/[tenantId]/access` | 租户权限 | P0 | 员工模块访问、动作权限、数据范围、字段权限 |
| `/platform/tenants/[tenantId]/dashboard` | Dashboard 配置 | P1 | 选择固定指标组件、过滤条件、排序和预览 |
| `/platform/tenants/[tenantId]/integrations` | 租户集成 | P2 | 飞书、电话 Bot、Webhook 实例配置与健康状态 |
| `/platform/tenants/[tenantId]/audit` | 租户审计 | P1 | 配置变更、代管、导入导出和权限变更 |

创建租户使用分步流程；在最终确认前不产生可登录租户，防止半配置状态被误用。

### 3.3 模板管理

| 路由 | 页面 | P | 核心功能 |
|---|---|---|---|
| `/platform/templates` | 模板列表 | P1 | 名称、版本、状态、使用租户数、复制草稿 |
| `/platform/templates/new` | 新建模板 | P1 | 从空白或现有租户配置创建草稿 |
| `/platform/templates/[templateId]` | 模板详情 | P1 | 对象、字段、视图、权限默认值和发布记录 |
| `/platform/templates/[templateId]/versions/[version]` | 版本对比 | P2 | 查看配置差异；选择性升级租户配置 |

已发布模板版本不可原地修改；修改产生新草稿版本。

### 3.4 业务对象设计器

| 路由 | 页面 | P | 核心功能 |
|---|---|---|---|
| `/platform/config/objects` | 对象列表 | P0 | 对象名称、代码、状态、字段数、使用范围 |
| `/platform/config/objects/[objectId]` | 对象设计器 | P0 | 基本设置、字段、状态、列表列、表单布局、预览 |

字段操作：

- 添加、编辑、停用、排序。
- 设置字段类型、必填、默认值、占位说明、单选项和校验。
- 设置员工 `EDIT` / `READ_ONLY` / `HIDDEN`。
- 发布前显示影响分析；有数据的字段不能直接改变为不兼容类型。
- 首期不提供永久删除，使用停用保留历史数据。

### 3.5 平台运营

| 路由 | 页面 | P | 核心功能 |
|---|---|---|---|
| `/platform/admins` | 平台管理员 | P1 | 邀请、停用、最近登录；不能删除最后一名管理员 |
| `/platform/jobs` | 后台任务 | P1 | 导入、导出、模板应用任务状态和失败原因 |
| `/platform/audit` | 平台审计 | P0 | 登录、租户生命周期、代管、配置和密钥变更 |
| `/platform/settings` | 平台设置 | P2 | 品牌、域名、邮件、存储和安全策略 |

## 4. 租户工作区

### 4.1 工作台与成员

| 路由 | 页面 | 用户 | P | 核心功能 |
|---|---|---|---|---|
| `/workspace/[tenantCode]` | 我的/公司工作台 | 管理员、员工 | P1 | 按角色展示指标、待办、最近记录和快捷新增 |
| `/workspace/[tenantCode]/members` | 成员管理 | 租户管理员 | P0 | 按手机号邀请、重发/撤销邀请、编辑、停用、查看未分配记录 |
| `/workspace/[tenantCode]/members/[memberId]` | 成员详情 | 租户管理员 | P1 | 基本信息、模块权限摘要、负责记录、操作历史 |
| `/workspace/[tenantCode]/members/[memberId]/access` | 成员访问配置 | 租户管理员 | P1 | 在平台默认策略范围内开关员工模块和动作；数据范围首期固定 OWN |
| `/workspace/[tenantCode]/import-export` | 导入导出中心 | 租户管理员 | P1 | 上传、映射、校验、导入结果、导出任务和限时下载 |
| `/workspace/[tenantCode]/audit` | 本租户审计 | 租户管理员 | P1 | 搜索操作者、对象、动作和时间；只读 |

### 4.2 通用对象页面

| 路由 | 页面 | 用户 | P | 核心功能 |
|---|---|---|---|---|
| `/workspace/[tenantCode]/objects/[objectCode]` | 记录列表 | 获准成员 | P0 | 视图、搜索、筛选、排序、分页、列设置、新增、批量操作 |
| `/workspace/[tenantCode]/objects/[objectCode]/new` | 新建记录 | 有 CREATE 权限成员 | P0 | 动态表单、校验、保存并继续/保存并关闭 |
| `/workspace/[tenantCode]/objects/[objectCode]/[recordId]` | 记录深链接 | 有 READ 权限成员 | P0 | 默认打开详情抽屉；可复制 URL、查看活动和审计摘要 |

列表页权限表现：

- 员工自动限制为 OWN，界面不提供切换到“全部”。
- 无 CREATE 权限时不渲染“新增”；后端仍执行权限检查。
- 批量分配、导出、删除仅对有对应权限的角色出现。
- 隐藏字段不能出现在列设置、筛选、导出和搜索结果中。

### 4.3 记录详情抽屉

抽屉包含：

- 标题区：主字段、状态、负责人、更多动作。
- 概要区：常用字段，可按权限就地编辑。
- 活动时间线：追加沟通记录、附件和下一步时间。
- 关联来源：线索、跟单、客户之间的来源链路。
- 审计摘要：创建人、创建时间、最近修改人和版本冲突提示。

抽屉内有未保存内容时，关闭、切换记录或离开页面必须确认。

## 6. 关键弹窗与系统组件

| 组件 | 触发场景 | 要求 |
|---|---|---|
| 分配负责人 | 单条/批量分配 | 显示当前值、目标成员状态、受影响数量 |
| 转为跟单 | 有效线索 | 展示字段映射、负责人、重复候选和确认结果 |
| 转为客户 | 成交跟单 | 展示客户映射、重复候选、来源保留和幂等结果 |
| 停用成员 | 成员管理 | 先显示其负责记录数，必须选择转移或保留未分配 |
| 导出确认 | 任意导出 | 明确范围、字段、敏感字段和预计记录数 |
| 权限不足 | 越权动作 | 指出不能执行的动作，不透露无权记录内容 |
| 版本冲突 | 多人编辑 | 对比“你的修改/当前版本”，允许刷新后重新编辑 |
| 邀请员工 | 成员管理 | 输入手机号、角色和模块权限；只显示“已发送/已存在”等安全结果，不泄露其他账号资料 |
| 接受邀请 | 登录后待办 | 显示目标公司、角色和邀请有效期；确认后创建成员关系 |

## 7. 页面状态清单

每个列表、详情和配置页面都必须设计并验收：

- 首次空状态：说明用途并给出一个主要动作。
- 筛选无结果：保留筛选条件并提供清除入口。
- 加载中：使用与最终布局相近的骨架，不让页面跳动。
- 局部失败：保留已加载内容，并允许重试失败部分。
- 全页失败：显示请求 ID 和重试/返回入口。
- 无权限：不展示敏感数据；避免用空状态伪装权限问题。
- 只读：控件使用只读展示而非仅 disabled 灰化，说明权限来源。
- 已停用/已归档：保留查看与审计，不允许普通编辑。

## 8. 登录后的路由决策

```text
没有活动 TenantMember
→ /waiting

只有一个活动 TenantMember
→ /workspace/[tenantCode]

有多个活动 TenantMember
→ /workspaces
```

待接受邀请不等于活动成员。用户接受邀请成功后重新计算目标路由；被撤销、过期或手机号不匹配的邀请不能创建成员关系。
