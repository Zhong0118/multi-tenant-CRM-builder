# CRM 平台页面设计规范 V2

> 本文定义所有角色共用的页面结构模式。  
> 具体“超级管理员有哪些页面以及每页内容”放在 `08-超级管理员页面规范.md`。

---

## 1. 页面结构分层

系统页面分为 3 层：

```text
A. Global Shell
   Sidebar
   Header
   User Menu

B. Page Pattern
   Dashboard
   List
   Detail
   Config
   Builder
   Audit

C. Business Content
   公司
   获客
   跟单
   客户
   期刊
   ...
```

开发时：

```text
Global Shell 只实现一次
Page Pattern 抽成通用组件
具体业务页只注入数据与配置
```

---

## 2. 用户角色

### 2.1 平台超级管理员

职责：

- 管理所有公司
- 配置公司功能
- 管理模板与表单
- 管理平台权限规则
- 配置 Dashboard
- 管理飞书集成
- 查看全平台日志
- 配置平台系统

### 2.2 公司管理员

职责：

- 查看本公司全部数据
- 管理本公司员工
- 查看公司 Dashboard
- 管理允许配置的业务内容

### 2.3 公司员工

职责：

- 完成自己的业务工作
- 查看自己负责的数据
- 填写/修改授权字段

所有角色共用：

## 4. Page Pattern：Dashboard

适用于：

- 平台总览
- 公司管理员首页
- 统计页

结构：

```text
Page Header
Date / Scope Filter
──────────────────────────────
KPI  KPI  KPI  KPI
──────────────────────────────
Primary Chart      Tasks
──────────────────────────────
Secondary Chart    Activity
──────────────────────────────
Detail Table
```

Dashboard 第一屏最多 6 个指标。

Dashboard 不应该做成“卡片墙”。

---

## 5. Page Pattern：List

适用于：

- 公司管理
- 获客
- 跟单
- 客户
- 员工
- 日志

结构：

```text
Page Header                         Primary Action
Description
────────────────────────────────────────────────
Search   Filter   Filter   More Filter
────────────────────────────────────────────────
Optional Summary / Tabs
────────────────────────────────────────────────
Table
────────────────────────────────────────────────
Batch Action                       Pagination
```

规则：

- CRUD 类页面优先使用 List Pattern
- 点击 Row 打开 Drawer
- 除非编辑内容非常复杂，否则不切新页面

---

## 6. Page Pattern：Detail

适用于：

- 公司详情
- 客户详情
- 跟单详情
- 用户详情

轻量详情：

```text
Table + Right Drawer
```

复杂配置详情：

```text
Full Detail Page
```

Full Detail：

```text
Page Header + Object Summary + Actions
Tabs
──────────────────────────────────────
Main Cards / Form
Side Activity / Tips
```

---

## 7. Page Pattern：Config

适用于：

- 公司配置
- 权限配置
- 系统设置
- 飞书设置

结构：

```text
Page Header
Tabs
────────────────────────────────────────
Left Context / Object List
Center Editor
Right Preview / Permission / Help
```

若只有一个对象，则使用：

```text
2-column Form + Right Info Panel
```

---

## 8. Page Pattern：Builder

适用于：

- 表单设计
- Dashboard 配置

结构：

```text
Page Header               Preview Save Publish
────────────────────────────────────────────────
Component/Field Library | Canvas | Property Panel
```

三栏比例推荐：

```text
240px | minmax(560px, 1fr) | 320px
```

Builder 不与普通 CRM 工作页混用视觉模式。

---

## 9. Page Pattern：Audit

适用于：

- 日志中心
- 集成事件
- 安全事件

结构：

```text
Page Header
Filter Bar
Summary
Tabs
────────────────────────────────────────────────
Log Table                       Event Detail
```

Detail 可固定右栏或 Drawer。

---

## 10. 页面内容密度

业务型页面：

```text
High density
```

配置型页面：

```text
Medium density
```

Dashboard：

```text
Medium-low density
```

禁止全站使用同一“大卡片 + 大留白”设计。

---

## 11. 面包屑

只有以下页面使用：

```text
公司管理 / ABC贸易
模板与表单 / 通用销售CRM / 客户表单
系统设置 / 安全策略
```

一级日常页面：

```text
获客
跟单
客户
```

不需要 Breadcrumb。

---

## 12. 页面主操作

每页最多一个 Primary：

```text
+ 新增公司
+ 新增线索
+ 新建表单
保存配置
发布
```

Secondary：

```text
导出
复制
预览
刷新
```

Danger：

```text
停用
删除
```

进入 More Menu 或 Detail。

---

## 13. 右侧 Drawer 使用场景

优先 Drawer：

- 查看一条记录
- 快速编辑
- 跟进历史
- 用户信息
- 日志事件

不用 Drawer：

- 创建公司
- 权限矩阵
- 表单 Builder
- 系统级配置
- Dashboard Builder

---

## 14. 全局搜索

平台管理员：

```text
公司
用户
模块
功能入口
```

公司管理员：

```text
客户
跟单
员工
业务记录
```

员工：

```text
自己的客户
自己的跟单
```

搜索结果必须尊重权限。

---

## 15. 通知

通知 Dropdown：

```text
待处理
系统
安全
```

点击通知直接进入对象页面。

不要把 Notification 做成独立社交 Feed。

---

## 16. 用户菜单

通用：

```text
Avatar
姓名
角色
────────
个人资料
账号与安全
────────
退出登录
```

多工作空间用户增加：

```text
切换工作空间
```

平台超级管理员不显示“切换公司业务数据”作为常规入口。

---

## 17. 页面状态

每页都需要设计：

```text
Default
Loading
Empty
Filtered Empty
Error
No Permission
Disabled
```

这些状态属于页面设计的一部分，不允许开发阶段再临时补。
