# 交互与样式约束

## 1. 设计方向

产品不是“炫目的 SaaS 展示页”，而是员工每天长时间操作的业务工作台。设计方向命名为 **Operational Ledger（业务账本）**：保持表格的熟悉、高密度和可扫描性，同时用清晰的流程轨迹、权限状态和历史记录解决 Excel 的缺陷。

页面的记忆点是 **账本轨**：详情抽屉左侧用一条克制的纵向轨迹展示“来源 → 当前阶段 → 下一步”，让记录的来路和下一动作始终可见。除这一处外不增加装饰性图形。

## 2. 设计令牌

### 2.1 颜色

| 名称 | Hex | 用途 |
|---|---|---|
| Ink Navy | `#162532` | 主文字、导航、强层级 |
| Paper Mist | `#F4F7F9` | 页面背景，不使用纯白铺满 |
| Work Blue | `#2563EB` | 主操作、链接、焦点 |
| Ledger Teal | `#0F766E` | 已完成、已验证、流程轨迹 |
| Review Amber | `#B45309` | 待审核、临期、警告 |
| Stop Red | `#B42318` | 错误、危险动作、逾期 |

卡片和表格表面使用 `#FFFFFF`；边框使用 `#D8E0E6`；次要文字使用 `#526473`。状态不得只依赖颜色，必须同时有文字或图标。

### 2.2 字体

- 中文正文与控件：`Noto Sans SC`，回退到 `PingFang SC`, `Microsoft YaHei`, sans-serif。
- 拉丁与数字：`IBM Plex Sans`，表格数字使用 tabular numerals。
- 指标标签和记录编号：`IBM Plex Sans Condensed`，只用于小范围功能性信息。
- 不使用大段全大写，不用装饰性手写字体。

### 2.3 字号与行高

| 角色 | 字号/行高 | 字重 |
|---|---|---|
| 页面标题 | 24/32 | 650 |
| 区块标题 | 18/26 | 600 |
| 正文/表格 | 14/22 | 400 |
| 控件标签 | 13/20 | 500 |
| 辅助/编号 | 12/18 | 450 |
| 关键指标 | 28/34 | 600 |

表格正文不得小于 13px。金额、数量和日期按列对齐。

### 2.4 间距与形状

- 基础间距单位 4px；常用间距 8、12、16、24、32。
- 页面内容最大宽度不固定，表格页优先使用可用空间；详情与配置表单限制行长。
- 控件高度：紧凑 32px、默认 36px；主要触摸操作最小 40px。
- 圆角：控件 6px、容器 8px、标签 4px；不使用大面积胶囊形状。
- 阴影仅用于浮层和抽屉，不用阴影区分普通区块。

## 3. 页面布局

- 桌面端顶部栏 56px，左侧导航展开 224px、收起 64px。
- 页面内边距：≥1440px 时 24px；1024–1439px 时 20px；窄屏 16px。
- 表格页采用“标题 → 工具栏 → 视图摘要 → 表格 → 分页”。
- 配置页采用左侧步骤/对象树 + 右侧编辑区，预览以分栏或抽屉呈现。
- 详情优先右侧抽屉，只有复杂配置或需要独立链接的深度内容使用全页。

## 4. 导航与命名

- 导航使用用户认识的业务名：“获客”“跟单”“客户”，不出现 `Object`、`Schema`、`JSONB`。
- 平台后台可以使用“业务对象”和“字段”，但必须提供示例说明。
- 同一动作全流程使用同一动词：按钮“转为客户”，成功提示“已转为客户”。
- 面包屑只用于三层以上配置路径；日常工作页面不堆叠面包屑。
- 当前租户在顶部持续可见；切换租户必须回到目标租户工作台。

## 5. 账号与邀请交互

### 5.1 账号表单

- 首期所有认证页面只使用手机号，不显示邮箱登录或邮箱找回入口。
- 注册分为手机号验证码、姓名和设置密码；发送验证码与提交注册分别限流。
- 验证码按钮显示剩余秒数，倒计时不阻止用户修改手机号；修改后必须重新获取验证码。
- 登录、注册和找回密码使用中性响应，不显示“手机号已注册/未注册”等可枚举信息。
- 表单提交期间禁用重复提交，但保留用户输入；网络失败后可以直接重试。
- `returnTo` 只接受站内相对路径，登录后仍需重新验证目标页面权限。

### 5.2 邀请与工作空间

- `/waiting` 只展示当前用户本人邀请和账号入口，不出现租户业务导航。
- 邀请卡片必须显示租户、拟授予角色、邀请人、到期时间和当前状态。
- 接受邀请前再次确认租户与角色；接受按钮具备加载状态和幂等保护。
- 邀请过期、撤销、已接受、已拒绝和手机号不匹配使用独立结果状态，不只显示 Toast。
- 一个活动工作空间自动进入 `/workspace/[tenantCode]`；多个活动工作空间进入 `/workspaces`。
- 工作空间卡片显示租户名称、角色和最近访问时间；停用项可见但不可进入，并说明原因。

## 6. 表格交互

### 6.1 基本规则

- 表头吸顶；首个主字段可冻结；横向滚动时保留行操作入口。
- 默认每页 50 条，可选 20/50/100；不使用无限滚动替代业务分页。
- 单击行打开详情抽屉；链接、复选框和行内控件阻止行点击。
- 双击不绑定关键动作，避免触控和可访问性问题。
- 选择记录后出现批量操作条，显示已选数量和范围。
- 列宽可调、列可隐藏；隐藏字段权限高于个人列设置。

### 6.2 搜索与筛选

- 搜索框延迟 300ms 后执行，按 Enter 立即执行。
- 筛选条件用可读标签显示，可单个删除或全部清除。
- 日期筛选明确使用哪个业务时间，不写含糊的“日期”。
- 筛选、排序、页码写入 URL；返回列表时保持上下文。
- 搜索无结果时区分“没有数据”和“当前条件无结果”。

### 6.3 行内编辑

MVP 默认不做任意单元格编辑。简单状态或负责人可在明确权限下快速修改；其他字段进入详情抽屉。快速修改仍需服务端校验、乐观锁和审计。

## 7. 表单交互

- 标签置于控件上方；必填用文字/符号并在提交时给出具体原因。
- 动态表单按业务小节分组，每节建议 4–8 个字段。
- 字段帮助说明只解释输入规则，不重复标签。
- 保存时保留用户输入；验证错误滚动并聚焦第一个错误。
- 只读字段用正常文本或只读组件展示，并附“仅管理员可编辑”等说明；不要只用低对比度 disabled。
- 隐藏字段不占布局，也不出现在提交载荷中。
- 危险变更（停用字段、转换、批量修改）必须显示影响范围。

## 8. 详情抽屉

- 桌面宽度默认 560px，复杂记录 720px；小于 768px 使用全屏抽屉。
- 标题区固定；内容区滚动；主要操作置于标题区或底部固定区，不重复两套主按钮。
- 账本轨展示来源、当前阶段、下一步和关键时间，点击节点跳到对应活动。
- 字段更新与新增活动是两个动作，不把活动内容覆盖到备注字段。
- 切换上一条/下一条记录时保留列表筛选上下文。

## 9. 状态、反馈与错误

- 成功 Toast 2–4 秒自动关闭，包含明确对象：“跟进记录已保存”。
- 需要用户继续处理的结果使用内联提示或结果面板，不能只用 Toast。
- 删除、停用、转换等不可逆或高影响动作使用确认弹窗；普通保存不确认。
- 错误信息说明发生了什么、哪一项需要改、如何继续；不写“操作失败，请重试”作为唯一信息。
- 403 与 404 不互相混淆；但跨租户资源可统一返回 404 防止枚举。
- 网络断开时保留未提交表单并提供重新提交，不能静默丢失。

## 10. 权限在界面中的表现

- 无模块访问权：导航中不出现，直接访问返回 403/404。
- 无动作权限：不渲染动作按钮；若权限在打开页面后变化，提交时返回明确提示。
- `READ_ONLY`：显示值和锁形说明，不显示可编辑控件。
- `HIDDEN`：页面、筛选、列设置、导出和打印中均不存在。
- OWN 范围：页面标题用“我的获客/我的跟单”；不提供伪装可用的“全部”筛选。
- 代管模式：顶部固定醒目标识，但不用遮挡主操作。

## 11. Dashboard

- 第一屏最多 6 个核心指标，之后是漏斗、趋势或员工表；不堆砌卡片。
- 每个指标可点击下钻到使用相同过滤条件的明细列表。
- 指标旁提供口径说明和最近更新时间。
- 图表颜色与状态语义一致，同一阶段跨页面颜色不变。
- 转化漏斗显示数量与转化率；员工业绩表显示分子和分母，避免只给百分比。
- 数据不足时直接说明样本范围，不用装饰性空图。

## 12. 动效

- 只保留一个编排重点：详情抽屉打开时账本轨节点按 120–180ms 轻微顺序显现。
- 页面切换、表格刷新和状态变化使用 120–200ms 的淡入/位移。
- 不使用持续发光、漂浮背景或大面积渐变动画。
- 尊重 `prefers-reduced-motion`，关闭非必要位移和顺序动画。

## 13. 响应式与移动端

- ≥1200px：完整导航、表格和右侧抽屉。
- 768–1199px：导航收起，次要筛选进入弹层，抽屉宽度不超过 70vw。
- <768px：底部/抽屉导航；列表转为重点字段卡片；详情全屏；保留搜索、筛选、新增和活动录入。
- 移动端不承诺平台配置、复杂导入和大规模批量操作；这些页面显示“请在桌面端完成”。

## 14. 无障碍验收

- 所有交互可用键盘完成，焦点顺序与视觉顺序一致。
- 抽屉/弹窗打开后焦点进入，关闭后返回触发控件。
- 表格排序、选择和分页有可读名称；图表提供文本摘要或数据表。
- 文本对比度符合 WCAG AA；焦点环不得被主题覆盖。
- 表单错误与字段通过 `aria-describedby` 关联。
- 图标按钮必须有可见 Tooltip 和无障碍名称。
