## 双层设计

```text
通用平台 MVP
├── 手机号注册与独立用户
├── 租户邀请与成员
├── 业务对象/字段配置
├── 表格、表单、详情与活动
├── ALL / OWN 数据范围
├── EDIT / READ_ONLY / HIDDEN 字段权限
├── Dashboard 配置
├── 导入导出
└── 平台级集成框架
          ↓ 应用业务模板
首家公司 CRM
├── 获客（电话 Bot / 人工外呼）
├── 线索审核与分配
├── 跟单及跟进活动
├── 转为客户
├── 期刊记录与管理员评级
└── 业务漏斗及员工业绩
```
