## 双层设计

```text
通用平台 MVP
├── 租户与成员
├── 业务对象/字段配置
├── 表格、表单、详情与活动
├── ALL / OWN 数据范围
├── EDIT / READ_ONLY / HIDDEN 字段权限
├── Dashboard 配置
├── 导入导出
└── 平台级集成框架
          ↓ 应用业务模板
首家公司 CRM
├── 获客（电话 Bot / 人工外呼）
├── 线索审核与分配
├── 跟单及跟进活动
├── 转为客户
├── 期刊记录与管理员评级
└── 业务漏斗及员工业绩
```

## 本轮不包含

- 可运行代码、数据库迁移或部署脚本。
- 首家公司实际 Excel 表头的最终字段定义；收到样表后在模板文件中补齐。
- 飞书、电话 Bot 和 AI 服务供应商的最终选型。
- 开发排期与任务拆分；设计确认后另行生成实施计划。
