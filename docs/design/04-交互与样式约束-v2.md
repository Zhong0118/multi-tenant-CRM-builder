# CRM 平台交互与样式约束 V2

> 适用范围：平台超级管理员、公司管理员、公司员工的全部桌面端页面。  
> 本文只规定“所有页面共同遵守的设计系统与交互原则”，不描述具体业务页面。

---

## 1. 设计目标

本产品不是营销型 SaaS 官网，而是企业员工每天长时间使用的业务工作台。

核心目标：

1. **低学习成本**：从 Excel 迁移过来的用户可以快速理解。
2. **高信息密度**：优先表格、筛选、详情，不用大面积装饰卡片占空间。
3. **权限清晰**：用户应明确知道“能看什么、能改什么、为什么不能改”。
4. **业务动作明确**：一个页面最多一个主操作，避免多个高亮按钮竞争。
5. **统一**：不同用户角色看到的页面结构不同，但基础交互、组件、间距和反馈完全一致。
6. **减少 AI 设计感**：不使用无意义渐变、彩色圆形图标底、过度圆角、卡通人物、装饰插画和大面积玻璃效果。

## 2. 视觉风格

设计关键词：

- Enterprise SaaS
- Neutral
- Dense but readable
- Table-first
- Low decoration
- Clear hierarchy
- Operational

不采用：

- 大面积渐变
- 玻璃拟态
- 霓虹高光
- 彩色阴影
- 每个模块一种颜色
- 大量胶囊按钮
- 卡通头像
- 插画式 Dashboard
- 为了“看起来高级”而增加的无意义留白

### 2.1 主色

| Token | 值 | 用途 |
|---|---|---|
| `--color-primary` | `#2563EB` | 主按钮、链接、焦点、选中 |
| `--color-primary-hover` | `#1D4ED8` | 主按钮 Hover |
| `--color-primary-active` | `#1E40AF` | 主按钮 Active |
| `--color-primary-soft` | `#EFF6FF` | 导航选中、轻提示背景 |

### 2.2 中性色

| Token | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#0F172A` | 标题、主文本 |
| `--text-secondary` | `#475569` | 次级说明 |
| `--text-tertiary` | `#64748B` | 辅助信息 |
| `--border-default` | `#E2E8F0` | 普通边框 |
| `--border-strong` | `#CBD5E1` | 强边框 |
| `--bg-page` | `#F8FAFC` | 页面背景 |
| `--bg-surface` | `#FFFFFF` | 表格、卡片、表单 |
| `--bg-hover` | `#F1F5F9` | Hover |
| `--bg-selected` | `#EFF6FF` | Selected |

### 2.3 状态色

| 状态 | 颜色 |
|---|---|
| Success | `#16A34A` |
| Warning | `#D97706` |
| Danger | `#DC2626` |
| Info | `#2563EB` |
| Disabled | `#94A3B8` |

状态必须同时包含文字，不允许只靠颜色表达。

## 3. 字体

推荐：

```css
font-family:
  Inter,
  "Noto Sans SC",
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;
```

数字使用 `font-variant-numeric: tabular-nums`。

### 字号

| 场景 | 字号 | 行高 | 字重 |
|---|---:|---:|---:|
| 页面标题 | 24px | 32px | 600 |
| 区块标题 | 18px | 26px | 600 |
| 卡片标题 | 15px | 22px | 600 |
| 正文 | 14px | 22px | 400 |
| 表格 | 14px | 20px | 400 |
| 表单 Label | 13px | 20px | 500 |
| 辅助文字 | 12px | 18px | 400 |
| KPI 数字 | 28px | 34px | 600 |

不使用 700/800 的超粗标题制造视觉冲击。

### 4.1 桌面端标准尺寸

```text
┌─────────────── 240px ───────────────┬───────────────────────────────┐
│ Sidebar                             │ Top Header 64px               │
│                                     ├───────────────────────────────┤

│                                     │                               │
└─────────────────────────────────────┴───────────────────────────────┘
```

标准值：

| 项目 | 规格 |
|---|---|
| Sidebar 展开 | 240px |
| Sidebar 收起 | 64px |
| Top Header | 64px |
| 内容区 Padding | 24px |

| 卡片内边距 | 20px |
| 表格工具栏高度 | 48–56px |

## 5. Sidebar 规范

Sidebar 是所有角色共同结构，但菜单项根据权限变化。

### 5.1 结构

```text
Logo / Company Name
────────────────────
一级菜单
一级菜单
一级菜单
...
────────────────────
收起菜单
退出登录
```

Logo 区高度与 Header 保持一致：64px。

### 5.2 菜单项

规格：

- 高度：40px
- 左右 Padding：12px
- Icon：18px
- Icon 与文字间距：10px
- 圆角：6px
- 菜单间距：4px
- 左右外边距：8px

### 5.3 状态

#### Default

```text
icon #64748B
text #334155
background transparent
```

#### Hover

```text
background #F1F5F9
text #0F172A
transition 120ms
```

#### Active

```text
background #EFF6FF
icon #2563EB
text #1D4ED8
font-weight 500
```

不使用彩色渐变，不使用发光。

#### Pressed

```text
background #DBEAFE
transform: none
```

按钮不需要明显缩放动画。

### 5.4 Sidebar 收起

收起后：

- 宽度 64px
- 仅显示图标
- Hover 后 Tooltip 显示菜单名称
- 当前菜单仍保留 Active 背景
- Logo 只保留符号
- `退出登录` 只显示图标

### 5.5 底部区域

底部固定：

```text
[ ← 收起菜单 ]
[ ↪ 退出登录 ]
```

退出登录：

- 不使用红色大按钮
- 默认中性色
- Hover 时文字变 `#DC2626`
- 点击后二次确认仅在存在未保存内容时出现

## 6. Icon 规范

推荐统一使用：

- Lucide Icons
- 或 Remix Icon

不要不同 Icon 库混用。

规格：

```text
普通导航：18px
按钮：16px
空状态：32px
描边：1.75px
```

禁止：

- 彩色 3D icon
- 每个图标不同背景色
- 卡通机器人 icon
- 彩色圆球 icon
- 大面积 icon halo

状态图标可以使用状态色，但普通业务 Icon 一律使用中性色或主色。

---

## 7. Top Header 规范

高度固定 64px。

结构：

```text
┌──────────────────────────────────────────────────────────────────┐
│ Breadcrumb / Workspace        Global Search        🔔  ?  User ▾ │
└──────────────────────────────────────────────────────────────────┘
```

### 7.1 左区

日常业务页：

- 显示 Workspace / 公司名称
- 二级页面可显示 Breadcrumb

平台后台：

```text
首页 / 公司管理 / 公司详情
```

Breadcrumb 最多 3 层。

### 7.2 中区：全局搜索

宽度：

- Desktop：320–420px
- 低于 1200px：可缩为 260px

Placeholder 示例：

```text
搜索公司、用户、模块或功能
```

支持：

```text
⌘ K / Ctrl K
```

打开 Command Search。

### 7.3 右区

顺序固定：

```text
通知 → 帮助 → 用户菜单
```

通知 Badge 最大显示：

```text
99+
```

### 7.4 用户菜单

触发区域：

```text
[Avatar 32]  张三
             公司管理员   ▾
```

平台超级管理员：

```text
[Avatar] 平台超级管理员 ▾
```

Dropdown：

```text
张三
138****1234
────────────
个人资料
账号与安全
切换工作空间（存在多个公司时）
────────────
退出登录
```

Avatar 使用：

- 用户真实头像
- 或姓名首字母圆形占位

不使用 AI 卡通头像。

## 8. Page Header

所有业务页面统一：

```text
页面标题                              [次要操作] [主要操作]
一句话说明 / 数据更新时间
```

例如：

```text
公司管理                              [导出] [+ 新增公司]
统一管理平台下所有公司
```

规则：

- 一个页面最多 1 个 Primary Button
- 次要操作使用 Secondary / Text Button
- 危险操作不放在页面主 Header
- 页面标题与工具栏之间保持 20–24px

---

## 9. Button

### Primary

- Height 36px
- Padding 0 14px
- Radius 6px
- Background `#2563EB`

### Secondary

- 白底
- Border `#CBD5E1`
- Text `#334155`

### Text Button

用于：

- 查看详情
- 编辑
- 更多
- 跳转

### Danger

只用于：

- 删除
- 停用
- 撤销不可恢复动作

不将 Danger 作为常驻大面积按钮。

---

## 10. Card

普通信息块：

```text
background #FFFFFF
border 1px solid #E2E8F0
border-radius 8px
box-shadow none
```

仅以下组件使用 Shadow：

- Dropdown
- Drawer
- Modal
- Popover

避免“每一块都是悬浮卡片”。

---

## 11. KPI

KPI 只用于 Dashboard / 总览，不用于普通管理页面堆装饰。

单个 KPI：

```text
Label
28
较上周 +2
```

Icon 允许使用单色 20px Icon。

不使用：

```text
彩色圆形底 + 渐变 icon + 大阴影
```

第一屏最多 4–6 个 KPI。

---

## 12. Filter Bar

统一结构：

```text
[搜索................] [状态 ▾] [负责人 ▾] [更多筛选]     [重置]
```

规则：

- Search 左侧
- 高频 Filter 直接展示
- 低频 Filter 收入“更多筛选”
- Filter 条件写入 URL
- 返回页面恢复筛选状态

Search：

- debounce 300ms
- Enter 立即搜索

---

## 13. Table

这是 CRM 最重要的组件。

规格：

| 项目 | 值 |
|---|---|
| Header 高度 | 40px |
| Row 默认高度 | 44px |
| Dense Row | 40px |
| Horizontal Padding | 12px |
| Table Font | 14px |

规则：

- 表头 Sticky
- 主要字段可冻结
- 行 Hover 使用 `#F8FAFC`
- Selected 使用 `#EFF6FF`
- 分页优先，不使用无限滚动
- 默认 20/50/100 条
- 单击行打开详情 Drawer
- 行内按钮不触发行点击

金额右对齐；数量右对齐；日期保持统一格式。

---

## 14. Drawer

详情优先 Drawer，而不是频繁切全页。

宽度：

```text
普通详情 560px
复杂详情 720px
```

结构：

```text
Title + Status                    X
Secondary info
─────────────────────────────────
Tabs / Sections
Content
─────────────────────────────────
Fixed Action Area（必要时）
```

Drawer 内不重复页面级导航。

---

## 15. Modal

只用于：

- 删除确认
- 停用确认
- 转换确认
- 小型配置

复杂表单不要塞入 Modal。

推荐宽度：

```text
420 / 520 / 640
```

---

## 16. Form

Label 在 Input 上方。

标准：

```text
Label
[ Input                         ]
说明 / Error
```

默认两列 Form：

```text
Desktop ≥ 1200px：2 columns
较复杂说明：1 column
```

只读字段：

```text
最终评级
A
仅管理员可以修改
```

不要展示灰掉的 Select。

---

## 17. Tabs

适用于详情、配置页。

样式：

- underline/tab line
- 不使用胶囊 Tabs
- Tab 高度 40px
- Active `#2563EB`

---

## 18. Status Tag

Radius 4px。

示例：

```text
已启用
待审核
已停用
已成交
已逾期
```

状态标签颜色必须跨页面一致。

---

## 19. Empty / Loading / Error

所有页面必须实现：

1. Loading
2. Empty
3. Search No Result
4. Error
5. No Permission

### Empty

```text
暂无公司
创建第一家公司后可开始配置 CRM

[+ 新增公司]
```

不用大插画。

---

## 20. 权限状态

### 没有页面权限

- Sidebar 不显示菜单
- 直接 URL 返回 403

### 没有操作权限

- 不显示操作按钮

### READ_ONLY

显示值，并在必要时显示：

```text
仅管理员可编辑
```

### HIDDEN

字段：

- 表格不存在
- 详情不存在
- Filter 不存在
- Export 不存在

---

## 21. 动效

统一：

```text
Hover 120ms
Dropdown 140ms
Drawer 180ms
Modal 160ms
Page Content 120ms
```

只使用：

- opacity
- transform 2–4px

不用弹跳、旋转、持续动效。

---

## 22. 响应式

优先级：

```text
Desktop > Tablet > Mobile
```

### >= 1440

完整 Sidebar + Table

### 1024–1439

Sidebar 默认可收起

### 768–1023

Sidebar 收起
Filter 收入 Drawer

### <768

平台超级管理员复杂配置页提示：

```text
该功能建议在桌面端使用
```

员工业务页面才重点优化移动端。

## 23. 设计验收

开发完成后必须检查：

- [ ] 页面只使用设计 Token
- [ ] Sidebar / Header 尺寸统一
- [ ] 页面只有一个 Primary Action
- [ ] Icon 使用同一套库
- [ ] 无无意义渐变
- [ ] 无卡通头像
- [ ] 无彩色装饰 Icon 背景
- [ ] Table 密度可满足 1280×720
- [ ] 权限状态有文字说明
- [ ] Loading / Empty / Error 完整
- [ ] Keyboard Focus 可见
- [ ] Drawer / Modal Focus 正确
