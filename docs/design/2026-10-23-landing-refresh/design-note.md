# 百杰 CRM 落地页改版（2026-10-23）

## 问题

线上版本（`crm.baijiehub.com`，`42e5974`）整页 9,890px：

- 多数章节要滚动到位才显示，截图和慢网络下出现大片空白；
- 线索公海是一段 240vh 的滚动动画；
- 正在路上一节把已上线的跨表自动化、联系结果、任务与日报、团队动态写成了“尚未上线”；
- 早期 `088a0b4` 版本里可切换场景的产品演示丢了。

## 方向

- **配色：** 白底，品牌蓝 `#1f5ad6`，浅蓝灰分段底 `#f3f6fa`，深色高对比文字。
- **结构：** 页面以产品演示为主角，标题收短到首屏上方三分之一，演示窗口在 1440×900 下完整出现在首屏。
- **参考：** 借鉴 Attio 的“产品界面即主视觉”和 Linear 的克制层级，没有沿用它们的文案或界面。

## 结构

1. **导航：** 产品 / 使用场景 / 常见问题 / 登录 / 创建账号；窄屏收进菜单。
2. **首屏：** 标题、一句说明、创建账号 / 登录工作区，下面直接是演示。
3. **演示：** 左侧五个场景（窄屏变为横向标签），右侧同一个产品窗口。窗口的人物、侧栏和面包屑随场景切换。五个场景共用虚构公司「禾木办公家具」：
   - **导入与整理：** 检查 → 必填缺失、导入按钮禁用 → 补填 → 导入并进线索池；
   - **分配与领取：** 导入的线索出现在公海；领取后 24 小时倒计时；未接通不推进，已接通 / 新加微信进入跟进中；
   - **跟进与提醒：** 已逾期 / 今天 / 未来 7 天；完成后安排下一次；消息面板可逐条或全部已读；
   - **团队进展：** 今天 / 本周 / 本月统计，查看日报，安排任务；
   - **AI 问答：** 回答附来源；修改只给待确认的建议，确认或拒绝。
   - 另有一条“示例数据”说明，以及“重置演示”（未操作时禁用）。
4. **产品能力：** 两宽两窄错落排列，每块配一个小产品片段：业务表、权限、公海与负责人、跨表关联与自动化。下面一行“还包括”。
5. **从注册到开始工作：** 三步，并说明注册后需管理员邀请才能进入公司。
6. **常见问题：** 8 条。
7. **页脚：** 公司名、有效导航、版权，备案号居中并链接到工信部。

## 动效

- 场景切换：同一窗口内淡入加 6px 位移，240ms。
- 分段控件和计数轻微弹跳。
- 菜单、消息面板、联系结果菜单的展开与收起有过渡；日报和安排任务用高度过渡。
- 常见问题用 `::details-content` 过渡，不支持的浏览器直接展开。
- 首屏没有入场动画，不劫持滚动，不自动轮播。
- `prefers-reduced-motion` 下全部关闭，横向标签的滚动也改为瞬时。

## 证据

- `before/`：线上整页（1440、390）。
- `after/`：本分支整页（1440、1280、900、390）。
- `after/scenarios/`：五个场景的操作中状态。
- `compare/`：前后对比拼图。

## 已知限制

- 极慢网络下，脚本加载完成前，演示只显示第一个场景，标签暂不可切换。
- 团队进展的统计表在 390px 宽时在窗口内横向滚动。
