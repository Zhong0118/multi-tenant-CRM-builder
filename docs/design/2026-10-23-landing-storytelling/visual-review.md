# CRM landing 独立视觉评审

依据当前桌面、手机、故事中段和整页截图。未打开页面，未验证五场景交互或动效。整页截图采用减少动态模式，四个故事阶段静态展开的长度不作为正常模式的节奏问题。

三秒测试：桌面缩到 480px、手机缩到 180px 后，第一眼仍是黑蓝大标题和两个按钮，像 2024–2026 年常见 SaaS 官网。品类是 B 端 CRM 说服型落地页；一线同类完成度要求首屏业务对象本身也能成为主视觉。当前具体的 CRM 数据与动作要到首屏下沿才出现。

问题：
1. **首屏主视觉仍较通用**。桌面的“客户名单.xlsx → 客户档案 → 跟进与询单 → 合同与回款”是四个小文字框；手机 390×844 首屏只露出导入卡片开头。“同一条业务记录逐步成交”尚未成为首屏能看出的造型，换掉标题便可用于其他协作工具。目标是让一条具体记录及其流转关系在标题附近成为可辨认的主角；以替换现有四个孤立节点的空间完成。验收：480px 缩略图仍认得出记录与阶段关系，390×844 能看到记录的主要状态。
2. **手机能力区出现连续套框**。“业务表按需搭建、权限、公海、跨表关联”四段均采用淡蓝圆角框包白色子卡，连续约四屏的构图相同；看完整页会从客户流转的叙事退回组件展示。目标是保留具体能力证据，合并重复的外层容器与说明层级，令每段只有一个业务焦点。验收：手机连续滚过四段时，主次和轮廓能明显区分，去掉框后信息仍对齐且主角更突出。

提升：
- **精致度**：桌面首屏副文案“从一份客户名单，到一次成交让数据……”缺少语句分隔；补成可顺畅读出的两句。能力说明里的“限制在服务端执行”是实现层说明，可删掉，让权限结果更直接。其余截图中的文字对齐、按钮比例与留白整体干净，没有可见重叠或裁切。
- **设计感**：最强一屏是深蓝背景上的南湖实验学校记录，客户、负责人、期限、沟通记录建立了实在的业务关系。离 8 分主要还差首屏达到这段的产品专属性，以及移动端能力区的构图节奏。
- **动效**：未看到录屏，不能判断首次出场、滚动形变、退出或操作反馈是否到位；主 Agent 需按正常速度验收。最值得验收的是同一客户卡片在领取、沟通、签约间的承接感，需让字段和归属的改变可跟随，而不是仅替换整张卡片。

保留：同一条“南湖实验学校”记录贯穿业务阶段；白黑蓝体系、深浅背景节奏，以及用真实字段解释权限、公海与 AI 数据边界的做法。
总分：7/10（静态视觉；首屏专属性与手机能力区节奏是到 8 分的主要差距）
