## 3. 登录与工作空间

### 3.1 登录

```text
┌─────────────────────────────────────────────────────┐
│                                                     │
│  CRM / 业务账本            欢迎回来                 │
│  把分散的 Excel            手机号       [          ]│
│  变成可协作的业务流程      密码         [          ]│
│                             □ 保持登录               │
│                             [ 登录 ]                 │
│                             注册账号 · 忘记密码      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

左侧不是营销轮播，而是简短说明当前产品价值。错误显示在对应字段和表单顶部，不暴露账号是否存在。

首期不提供邮箱登录。登录成功后，无活动成员关系进入 `/waiting`，一个活动工作空间进入 `/workspace/[tenantCode]`，多个活动工作空间进入 `/workspaces`。

### 3.2 手机号注册

```text
┌──────────────────────────────────────────────┐
│ 创建账号                                     │
│ 注册只创建个人账号，加入公司需要接受邀请     │
│                                              │
│ 手机号       [ 138 **** ****              ] │
│ 验证码       [          ] [获取验证码 60s] │
│ 姓名         [                              ] │
│ 设置密码     [                              ] │
│                                              │
│ [ 创建账号 ]               已有账号，去登录 │
└──────────────────────────────────────────────┘
```

发送验证码和提交注册分别限流。密码规则在输入时显示；手机号已经存在时，接口返回不具枚举性的统一提示，并引导用户尝试登录或找回密码。

### 3.3 等待加入公司

```text
┌────────────────────────────────────────────────────┐
│ 你好，王明                                         │
│ 账号已经准备好，接受公司邀请后即可开始工作。       │
│                                                    │
│ 待接受邀请                                         │
│ ABC 期刊服务                                       │
│ 邀请角色：员工 · 邀请人：张总 · 2 天后过期        │
│                         [拒绝] [查看并接受]        │
│                                                    │
│ 没有看到邀请？ [输入邀请码] [刷新]                │
│                                                    │
│ 账号安全                                      退出 │
└────────────────────────────────────────────────────┘
```

- 没有邀请时说明“请联系公司管理员按此手机号邀请你”，不展示可浏览的公司目录。
- 接受前再次展示公司和角色；接受后根据活动成员数量进入工作台或工作空间选择页。
- 独立用户不能看到租户导航、业务搜索或任何 CRM 数据。

### 3.4 选择工作空间

卡片显示租户名称、本人角色和最近访问时间。默认聚焦最近使用租户；停用租户保留显示但不可进入，并说明原因。

- 点击租户进入概览，不直接进入其业务数据。

## 5. 创建租户流程

```text
1 基本信息 ── 2 选择模板 ── 3 邀请首位管理员 ── 4 配置确认
```

每一步可返回修改；第三步填写首位管理员手机号，系统只创建邀请，不代设其密码。第四步列出将创建的对象、字段和权限摘要。点击“创建租户”后显示后台任务进度，失败时保留草稿和可重试步骤。

## 6. 业务对象设计器

> 实现状态（第二切片已完成）：租户端设计器位于
> `/workspace/[tenantCode]/settings/objects/[objectId]`，采用「基本设置 / 字段 / 列表视图 /
> 员工权限 / 发布记录」左侧步骤栏，签名元素为单行 FIELD LEDGER。发布前先展示影响面板，
> 阻断项无法确认，版本冲突保留草稿并提供重新载入。平台端 `/platform/config/objects`
> 仍是后续切片的模板设计器，尚未实现。

```text
客户管理 / 业务对象设计器                 [预览] [发布变更]
┌──────────────────┬─────────────────────────────────────────┐
│ 基本设置         │ 字段（12）                    [＋字段]   │
│ 字段             │ ┌─────────────────────────────────────┐ │
│ 表单布局         │ │ ≡ 客户名称  文本     必填     编辑  │ │
│ 列表视图         │ │ ≡ 电话      电话     必填     编辑  │ │
│ 状态             │ │ ≡ 最终评级  单选     可选     只读  │ │
│ 权限             │ └─────────────────────────────────────┘ │
│ 发布记录         │                                         │
│                  │ 选择字段后在右侧/抽屉编辑配置            │
└──────────────────┴─────────────────────────────────────────┘
```

- 拖动只改变展示顺序，不改变 `field_key`。
- 字段权限直接显示文字，避免仅靠锁图标。
- “发布变更”先展示新增、停用、类型改变和数据影响。
- 预览允许切换管理员/员工角色，验证隐藏和只读状态。

## 10. 权限表现

### 10.1 只读字段

```text
最终评级
A  🔒 由管理员确认
```

不要显示一个灰到难以阅读的下拉框。员工提交载荷中不包含该字段，API 对伪造字段返回 403/422。

### 10.2 隐藏字段

隐藏字段在详情、列表列、筛选、导出和打印中均不可见。空白占位也不能泄露字段存在。

## 11. 导入向导

```text
1 上传文件 → 2 选择表头 → 3 字段映射 → 4 校验预览 → 5 导入结果
```

校验预览将数据分为“可导入、需修正、将跳过”，显示前 100 条和完整错误下载。执行前显示负责人默认值、重复处理规则和预计写入数量。

## 13. 设计验收清单

- 所有 P0 页面具备默认、加载、空、无结果、错误、无权和只读状态。
- 管理员与员工预览能明确看出 ALL/OWN 和字段权限差异。
- 页面刷新、详情深链接和浏览器返回不会丢失列表上下文。
- 1280×720 下核心表格仍能看到标题、工具栏、至少 8 行数据和分页。
- 390×844 下可完成查看记录、新增活动和修改获准字段。
- 键盘可完成搜索、筛选、打开抽屉、编辑、保存和关闭。
- 颜色、字号、圆角和间距只使用令牌，不直接散落魔法值。
