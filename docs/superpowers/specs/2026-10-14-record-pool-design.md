# 按业务表启用的公共池

用户已确认：保留共享业务表和负责人结构，按表启用公共池，实现领取、手动释放、管理员分配、到期自动回收；仅本地开发测试，不部署。

## 数据与权限

- 复用现有记录，不创建第二份业务数据或额外侧栏业务表。
- 每个对象保存 enabled（默认 false）、ownershipTtlHours（null 表示不自动回收）、配置 version。管理设置立即生效，明确提示无需发布，独立于业务字段草稿。
- 每条记录增加 inPublicPool（默认 false）与 ownershipExpiresAt（默认 null）。旧记录不回填、不因 owner=null 入池。
- 领取仅允许可读且可编辑该表的活动成员；释放允许负责人本人且具备编辑权限，或租户管理员。管理员可将未分配、公共池、他人名下记录分配给本租户活动成员。
- 公共池只为该表可读成员开放，仍过滤隐藏字段；OWN 员工不能访问他人的私有记录。公共池记录在领取前对员工只读。
- 领取/分配按当前小时数计算新期限；释放清空负责人和期限并显式入池。普通内容修改不续期。已有无期限记录不自动补期限。
- 关闭公共池时保留记录和状态，暂停领取/释放/回收；管理员仍可处理分配。重开后历史到期记录恢复回收。界面明确提醒。调整 TTL 不追溯修改已经确定的期限。
- 到期回收由 API 生命周期定时扫描（现有 worker 尚无业务任务注册），不依赖访问页面；限批、可重复、并发安全、停止时清理计时器，失败记录日志且后续继续。
- 流转使用事务、版本检查和行锁/条件更新，多个成员同时领取只有一个成功；配置与状态竞态不得导致关闭后继续回收。审计与变更同事务。
- 现有编辑/导入/工作流修改负责人必须维持系统属性一致，不得形成同时有负责人又在公共池中的状态；不允许通过普通编辑替代员工领取。

## 前端与接口约定

- 同一业务表页面增加 我的记录 / 公共池 / 全部记录，全部记录仅 read=ALL 可见。未启用时保持原界面。
- 查询参数 scope=mine|pool|all；省略时保留现有行为。切换重置分页与负责人筛选，保留搜索排序和业务字段筛选；URL 与抽屉返回保持一致。
- GET/PATCH /workspaces/:tenantCode/objects/:objectCode/pool-config：{enabled:boolean, ownershipTtlHours:number|null, version:number}。PATCH 要求 version（乐观并发）及完整配置；范围 1–8760 小时。
- POST /workspaces/:tenantCode/objects/:objectCode/records/:recordId/ownership：{action:'CLAIM'|'RELEASE'|'ASSIGN', version:number, ownerMemberId?:string}，返回 {recordId:string,version:number}。ASSIGN 必须有目标成员，其他动作不能夹带目标成员。
- 记录响应增加 inPublicPool:boolean、ownershipExpiresAt:string|null。详情只对可读公共池记录放宽读范围，写权限不放宽。
- 管理员在表页面打开公共池设置；使用现有 Drawer、Select、InputNumber、Switch、按钮，加入现有风格的过渡，尊重 reduced-motion。
- 列表/卡片/详情区分 公共池 / 未分配 / 已分配，按需显示到期时间。领取/释放/分配后刷新服务端结果，释放后不留失去权限的详情。失败提示可操作，不使用空态掩盖 API 错误。

## 验收

默认关闭、旧数据不动、两个对象隔离、跨租户禁止、隐藏字段不泄露、只读成员不能领取、不能释放他人记录、非活动分配目标禁止、并发领取单一胜者、过期/删除/关闭处理、审计原子性、普通编辑不续期、URL 保持、移动桌面交互。迁移仅本地运行，记录迁移前后数据一致证据。测试、类型检查、契约生成、构建及浏览器全流程通过后交付。
