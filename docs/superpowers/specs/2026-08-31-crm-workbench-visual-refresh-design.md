# CRM 工作台视觉改版设计

## 目标

以已确认的合并视觉稿为方向，重做公司管理员与员工工作台的信息结构，并统一登录注册页面的视觉尺度。重点是可用、清楚、全宽，不追求像素级复刻或额外装饰。

## 视觉基准

- 选定稿：`/Users/zhongxu/.codex/generated_images/01a03ce8-3c33-7f63-b447-1def9ff77556/exec-8e18c43f-52d4-41a0-8745-1b8d74caceb4.png`
- 桌面基准：1440 × 1024。
- 深蓝固定侧栏；侧栏与正文独立滚动。
- 主内容占满侧栏以外的可用宽度。
- 指标与图表容器允许 8–12px 圆角；表格、工具栏和列表保持直角或小圆角。
- 颜色以深蓝、墨色、青绿色为主，蓝/绿/橙/红只表达业务状态。

## 管理员工作台

1. 页头标题改为“运营驾驶舱”，保留周期和指标配置入口。
2. 主要操作为“新建业务记录”；业务表管理降为次级操作。
3. 顶部使用连续指标带，不拆成大量卡片。
4. 主分析区左侧展示成交趋势，右侧依次展示销售漏斗和异常待办。
5. 员工业绩排行使用全宽紧凑表格，可排序，并给出直观的金额进度表达。
6. 风险业务明细和业务表入口继续保留，避免丢失现有功能。

## 员工工作台

1. 与管理员共用同一视觉体系。
2. 只展示个人权限范围内的指标、趋势、漏斗、待办和优先记录。
3. 不展示团队排行榜或管理员配置入口。
4. 有创建权限时提供“新建业务记录”主操作。

## 登录与注册

- 共用现有 `AuthShell`，不改注册页用户正在编辑的页面文件。
- 表单区域扩大，输入框、密码框和主按钮统一为 46px 左右。
- 使用更均衡的左右布局，减少空洞感，保持企业产品的克制感。

## 非目标

- 不修改 Dashboard API、指标口径或数据库。
- 不伪造同比、目标值或趋势数据。
- 不新增图片素材、复杂动效和多余图表。
- 不进行部署；只完成本地可运行和关键页面检查。

## 验收

- 1440px 桌面下正文充分利用横向空间，无异常横向滚动。
- 管理员与员工工作台的核心操作、筛选链接和表格排序仍可使用。
- 登录表单控件高度明显改善。
- 现有工作台单元测试、Web 类型检查通过。
- 浏览器检查登录页和管理员工作台，无阻塞级控制台错误。
