# 电话外呼设计（用户已批准）

## 授权与范围
2026-10-30 用户批准：业务表内拨打、独立通话记录页、管理员电话配置；独立 worktree 和 PR，本地开发测试，不合并、不部署、不真实拨号。企业 ID 与密钥拿到后另行真实联调。现有其他工作树、公司配置和数据不修改。

## 交互与业务边界
公司设置增加“电话外呼”，工作导航增加“通话记录”。管理员配置公司接入、员工坐席及接听手机号、员工外呼开关、业务表电话字段。员工从有权限的记录发起回拨；主叫始终是当前操作成员的绑定号码，不能指定任意 caller 或 callee。多个电话字段明确选择。支持已发布且未停用的 PHONE/TEXT 字段，号码值服务端从记录读取，支持中国大陆手机号码及 +86 前缀，不猜测其他格式。
表格电话值旁/记录详情提供拨打入口和抽屉，说明先接听自己手机。共享通话列表用于独立历史页和记录详情中的通话历史。可以回到原记录继续使用原有跟进/下次跟进功能，不另造跟进编辑器。
独立通话页员工仅自己的呼叫，管理员本公司；记录内历史基于当前记录与所选电话字段读取权限（组长复用现有组员记录授权），记录与字段权限撤销后，号码、录音、记录标题与链接不得泄露。通话记录统计不扩大数据权限。
一次请求、接通、询单、成交是不同事实。通话回写不自动改变负责人、公海阶段、期限、询单、成交保护，不使用会自动 CONFIRM_CONTACT 的人工跟进命令。真实最终话单只记录一次 CALL 活动，与现有工作统计衔接；模拟通话不计入真实 CALL 统计、不更改业务记录。

## 供应商协议（以已读快马后台文档为准）
文档 https://share.note.youdao.com/s/WynHdEp5 （后台 /open.html?v=11 同源指向）。固定供应商 origin https://www.kuaimatongxun.com；不开放管理员任意 URL，避免 SSRF。
企业 POST /api/call/callBind，表单 company_id、ts（秒级）、sign=uppercase(MD5(company_id+app_secret+ts))、api_type=companyapi、type=2、caller、callee。code=1 且非空 bind_id 才是已受理，不能视为接通。文档例子 platform 与参数表 api_type 不一致，本轮依参数表实现并单测，真实联调前确认。
话单 push_type=1，录音 push_type=2，bind_id,seats_id,telA,telB,telX,status(1接通0未接通),begin_time,end_time,duration,audio_url。话单成功应答 {code:0}。挂断 status=End 只作为结束事件，不能推断接通。挂断通知是否适用电信专线2、回调鉴权、重试/补查、线路继承待供应商确认。
只做本地模拟与协议单测；不会用网页登录凭据拨打，不会运行真实供应商请求。

## 后端与安全
复用 Nest、Prisma、PostgreSQL RLS、现有对象/记录权限解析、审计和 React Query。无需新依赖、独立数据库或普通业务表。
新增最少专用存储：租户电话配置、成员坐席绑定、通话记录。所有关系租户约束与 RLS，新增迁移不改旧业务数据。配置按版本保存防覆盖；密钥加密存储（Node AES-256-GCM，32 字节 TELEPHONY_ENCRYPTION_KEY 环境密钥），不返回明文/审计/日志，空密码更新保持旧值。
本地支持 MOCK 模式，标识模拟；生产禁止 MOCK。KUAIMA 必须另有 TELEPHONY_LIVE_ENABLED=true 且完整配置才允许请求，否则明确不可用。默认关闭。不用随机密钥覆盖长期加密配置。
回调须具备单独租户验证凭据：Authorization Bearer callbackToken（管理员输入、加密、恒时比较）。供应商能否发送该 Header 待确认，故真实开关保持关闭；不能把未知协议猜成已验证。Origin guard 仅给这个经过身份校验的 webhook 处理器受控豁免，保留所有普通 API 的 CSRF。拒绝无凭据、错误租户/号码/坐席/未知 bind_id；body 严格校验，拒绝异常录音 URL，不在服务端任意抓取音频。
先存本地请求 ID 再发起一次外部请求，租户/成员/幂等键唯一、并发重复不重复拨号；同一成员另一个未结束请求阻止连点多拨。提交结果不确定使用 UNKNOWN（待核实），网络超时不重试拨号。网络调用在数据库事务外。多次相同/乱序话单不重复活动，不将已结束结果降级，录音可晚到；供应商唯一 ID 冲突不能串联其他通话。模拟使用同一结果归并逻辑。
记录结果关联发起时 recordId 和 actorMemberId，不以电话搜索匹配。列表分页筛选、时间显示 Asia/Shanghai；保存真实供应商原文需最小化，错误消息不回显供应商密钥/完整响应。
