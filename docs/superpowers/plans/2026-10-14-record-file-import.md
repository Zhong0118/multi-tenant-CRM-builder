# Excel / CSV 导入完善计划

> 使用 executing-plans 执行；独立后端任务按 subagent-driven-development 委派，并进行整体验证。

**目标**：用户一次选择完整 CSV/XLSX/XLS 文件，自动识别中文编码，选择工作表和字段映射，检查错误与重复后分批导入、查看进度、恢复中断、下载失败明细。

**架构**：浏览器解析文件（Excel 解析库按需加载）；复用 POST records/import，每请求最多 500 行，UI 使用较小批次。后端新增 dryRun 与 matchFields；复用现有字段/权限验证，返回 READY/CREATED/SKIPPED/FAILED。同文件内容和工作表生成稳定 UUID，使用现有数据库导入行账本。跨文件按已选字段精确匹配跳过，不覆盖。无需迁移或独立后台队列。

**技术**：Next/React/Ant Design、Nest/Prisma/PostgreSQL、SheetJS CE、Web Crypto。

## 约束与边界
- 本地修改/验证，不改线上业务数据；前序权限与 CSV 修复提交保留。
- 支持 UTF-8、带 BOM UTF-16、UTF-8 失败后尝试 GB18030；明确显示识别结果，允许手动选择并检查预览。拒绝替代字符和明显二进制 CSV。
- Excel 支持工作表选择，保留文本/格式化数字（手机号、前导零），日期标准化后交给已有字段转换。拒绝伪装后缀、不执行公式/宏。
- 文件初始上限 10MB / 10000 数据行 / 40 列，拒绝超限而不截断；500 为单请求上限，不再要求用户拆表。
- 同文件、同工作表、同成员重试稳定 batchId；映射和编码导入开始后锁定。同文件重选不重复新增成功行。文件修改后是新内容，应同时选业务查重字段。
- matchFields 可选择 1–3 个已映射、可编辑的标量字段；多字段联合精确匹配，空值不自动认为重复。权限遵守可见范围，不返回重复记录内容。文件内重复及已有数据重复默认跳过。
- dryRun 不创建记录/审计/导入账本。实际导入再次校验以应对发布或数据变化。导入间查重锁覆盖不同批次；这不替代业务全局唯一约束。
- 页面关闭会停止后续批次；重选原文件和工作表继续，已提交的请求可能完成。网络异常停止，保留已知结果；不盲目重发。失败明细含源行、原因、原始值，CSV 防公式注入。
- 不实现覆盖更新、姓名绑定成员、后台任务系统或恢复已丢失的乱码原文。

## 执行任务
1. 后端：DTO/返回类型、dryRun 复用验证、查重与跨批次锁、重试 SKIPPED；先写失败回归，验证租户/权限/无写入/重复/边界。生成 contracts。
2. 文件解析：自动编码、XLS/XLSX 工作表和类型处理、稳定 batchId、限制/失败 CSV；测试真实编码与两种 Excel 格式。
3. UI：工作表、查重字段、检查→导入、顺序分批、进度/中断恢复、失败明细；保留原映射和错误行为，测试超过 500 行及响应丢失。
4. 验证：相关测试、API/Web typecheck、受影响 lint、contracts、浏览器流程；记录结果和限制，不宣称未经验证的生产部署。

## 验收
- GBK 自动正确预览；UTF-8/UTF-16 保持正常；乱码文件阻止写入。
- XLS、XLSX、多工作表、日期、前导零可读；超限/坏文件有明确提示。
- 501+ 行无需拆文件；进度准确；失败行可下载，成功行重试不新增。
- 检查不写数据；字段错误可定位；不同文件相同业务键跳过，不跨租户/权限泄露。
- 关闭/网络中断后，同内容重选可恢复；显示实际成功/跳过/失败。
