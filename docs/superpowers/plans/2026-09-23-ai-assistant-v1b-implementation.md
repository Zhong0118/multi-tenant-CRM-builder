# AI Assistant V1B Confirmed Edit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a workspace member preview and explicitly confirm exactly one record update, self-assigned follow-up, or NOTE activity proposed by AI, with current-actor authorization and atomic, traceable execution.

**Architecture:** Extend existing tenant-scoped AI conversations with an RLS-protected operation linked to the producing turn. Separate provider-side candidate creation from confirm-time transaction-aware domain commands. Use one `RecordsRepository.withTenantTransaction` transaction (backed by `DatabaseContextRunner.withTenant`) for proposal lock, current schema/access resolution, business mutation, audit and EXECUTED status; failed transactions roll back, then persist a safe failure state in a separate conditional operation transaction. The existing chat renders only server-validated Proposal Cards; the existing read tools remain unchanged.

**Tech Stack:** Node >=24, pnpm 11.19.0, NestJS 11, Prisma 7/PostgreSQL 18/FORCE RLS, Zod 4, Vercel AI SDK Core, Next.js 16/React 19, Ant Design 6, Jest, Vitest, OpenAPI contracts.

**Spec:** `docs/superpowers/specs/2026-09-23-ai-assistant-v1b-design.md`

- `RecordsService.createActivity` in `records.service.ts:663-722` owns NOTE-compatible validation and audit but has no transaction-aware exported command yet.
- `createFollowUpCommand` in `follow-up-command.ts:177-215` already accepts a transaction but expects *caller*-validated title/date and permission scope. Existing `FollowUpsService.requireRecord` opens other transactions; do not call it from Confirm.

- `AiMessage` has only text/tool/source; proposal restoration needs a safe operation summary keyed by conversation and turn. Retry reuses a turn ID: prevent duplicate live proposals when retrying.
- `record_follow_ups` contains title/dueAt but no description: no follow-up description migration.
