# 快马回拨：电话外呼

员工在有权限的业务记录上点电话图标，系统让快马线路先拨员工自己的手机，员工接听后线路再拨给客户。通话结束后，结果自动回到原记录。

本文说明怎么配置、怎么使用、系统有哪些保护，以及真实打一通需要满足的条件。要问快马客服的问题见 [kuaima-vendor-questions.md](kuaima-vendor-questions.md)。

> 状态（2026-11-27）：只在本地用模拟线路和本地假快马验证过，还没有用真实线路打过电话。不能把本地验证当作真实线路已通过。

## 管理员配置

入口：设置 → 集成 → 电话外呼。每一项改动都单独保存，改完立即生效。

| 项目         | 说明                                                                                                                         |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 电话外呼     | 总开关。关闭后员工看不到电话图标，「通话记录」也不会出现在导航里。                                                           |
| 线路         | 「模拟」：不拨真实电话，直接记为已接通 30 秒，也不写跟进动态；正式环境不能用。「快马回拨」：走真实线路。                     |
| 企业账号     | 快马分配的企业 ID 和企业密钥。密钥加密保存，存好以后谁都看不到原文；要改就重新填写，留空表示不修改。                         |
| 回调地址     | 点「生成」得到一个带凭据的地址，只显示这一次。复制后发给快马客服，让对方配置为话单推送地址。点「重新生成」后旧地址立即失效。 |
| 真实外呼     | 由服务器配置 `TELEPHONY_LIVE_ENABLED` 决定，页面上只能看、不能改。没开通时，选了「快马回拨」也拨不出去。                     |
| 可拨打的号码 | 每张业务表单独选，指定哪些电话或文本字段可以拨打。实际只拨中国大陆手机号（11 位，可带 +86）。                                |
| 成员坐席     | 给每位成员填快马的坐席号和接听手机，再打开「允许外呼」。管理员自己要打电话，也需要配置自己的坐席。                           |

在这里配置可拨打的字段，不会让员工多看到任何内容：员工能看到哪些记录、哪些字段，仍按原来的权限决定。

## 员工使用

1. 记录页、列表和手机卡片上，允许拨打的手机号旁边有电话图标。图标是灰色时，把鼠标放上去可以看到原因，例如「你还没有外呼坐席，请联系管理员」。
2. 点图标后会弹出拨号窗口，显示两个号码：客户电话，和线路先回拨的「我的手机」。如果这条记录有多个可拨打的号码，先选一个。点「呼叫」就开始拨，不需要再勾选确认。
3. 窗口里直接显示进度和结果：

   | 显示                       | 含义                                                             |
   | -------------------------- | ---------------------------------------------------------------- |
   | 正在回拨你的手机…          | 快马已受理，接下来会先打你的手机                                 |
   | 线路没有明确回应，等待结果 | 网络中断或快马的回复看不懂。系统不会自动重拨，等话单回来再定结果 |
   | 已接通 · 1 分 05 秒        | 话单显示已接通                                                   |
   | 未接通                     | 话单显示没接通                                                   |
   | 线路拒绝 + 原因            | 快马直接拒绝了这次拨号，例如套餐不可用                           |

4. 拨出 1 分钟后还没有结果，可以点「结束这通」。一位成员同一时间只能有一通没结束的电话。
5. 通话结束后可以点「写跟进」，记录沟通内容。

真实线路打完一通，系统会在记录的「动态」里自动加一条，例如「电话外呼：已接通，通话 42 秒」。这条自动记录不计为人工跟进，不会延长公共池的跟进期限，也不会把记录变成询单或成交。

记录页的「通话」标签列出这条记录的所有通话。左侧导航的「通话记录」页：员工只看到自己拨的电话；管理员能看到全公司的，并可以按成员、结果、日期筛选。

## 保护措施

- **密钥**：企业密钥和回调凭据用服务器主密钥环（`AI_MODEL_KEYRING`）加密保存。加密结果只对本公司、本字段有效，换到别的公司或别的字段都解不开。保存后接口不会返回原文。
- **号码来源**：要拨的客户号码由后端从允许拨打的字段里读取，前端不能指定任意号码。点「呼叫」时，前端会带上窗口里显示的两个号码；后端发现号码已经变了，就拒绝拨号，要求重新核对。
- **不重复拨号**：每次打开拨号窗口都有一个请求编号。网络中断后再点「呼叫」，用的还是同一个编号，服务器只会返回原来那通电话，不会再拨一次。拨号超时或者看不懂快马的回复，都记为「待核实」，不会自动重拨。
- **回调校验**：回调必须带上正确凭据，可以放在网址的 `?token=` 里，也可以放在 `Authorization: Bearer` 请求头里，凭据错了返回 401。同一条话单重复推送、先推录音后推话单、挂断通知比话单先到，结果都一样。多出来的字段会被忽略，不会导致快马反复重推。
- **权限收回**：成员一旦看不到原记录或那个电话字段，通话页面就不再显示对应的客户号码、录音和记录链接。
- **录音链接**：只接受公网 HTTPS 地址。内网地址、带账号密码的地址都会被拒绝。
- **日志**：请求日志不记录网址里的参数，回调凭据不会出现在日志里。

## 回调接口（给快马客服配置）

```
POST {API_ORIGIN}/api/v1/telephony/hooks/{公司内部 ID}?token={凭据}
```

完整地址在设置页点「生成」后显示，直接复制即可，不需要自己拼。收到推送后返回 `{"code":0}`。请求体用 JSON 或表单都可以。

| 推送                                  | 系统处理                                                           |
| ------------------------------------- | ------------------------------------------------------------------ |
| 话单 `push_type=1`，`status=1` 或 `0` | 记为已接通或未接通，同时记下时长和开始、结束时间（按北京时间解析） |
| 录音 `push_type=2`，带 `audio_url`    | 给这通电话附上录音，不改变接通结果                                 |
| 挂断 `{bind_id, status:"End", time}`  | 如果电话还没出结果，记为已结束；之后再收到话单，仍按话单更新结果   |

话单里的 `seats_id`、主叫号码 `telA` 和被叫号码 `telB`，必须和拨号时一致，否则不予采纳。

## 服务器配置

| 变量                      | 默认值  | 说明                                                                                                  |
| ------------------------- | ------- | ----------------------------------------------------------------------------------------------------- |
| `TELEPHONY_LIVE_ENABLED`  | `false` | 设为 `true` 才会真正调用快马拨号接口                                                                  |
| `AI_MODEL_KEYRING`        | 已有    | 用来加密企业密钥和回调凭据。没配置时，管理员保存密钥会提示「服务器主密钥环未配置」                    |
| `TELEPHONY_KUAIMA_ORIGIN` | 空      | 只用于本地演练：把拨号请求转给本机的假快马。正式环境、或者地址不是 localhost / 127.0.0.1 时，一律忽略 |

数据库迁移：`0066_tenant_telephony`，只新增表，不改动现有数据。

## 真实打一通的条件

1. **回调地址必须是公网 HTTPS，快马的服务器能访问到。** 正式环境 `https://crm.baijiehub.com` 满足这个条件。内部测试环境只能通过 SSH 访问，本机的 localhost 快马也访问不到。
2. **拨号请求从我们的服务器发出。** 如果快马要求 IP 白名单，要把正式服务器的公网 IP `62.234.18.169` 加进去。本机的出口 IP 不固定，很可能被拒。
3. **服务器时间要准。** 签名里的时间戳与快马服务器相差不能超过 10 秒。
4. **部署。** 本分支合并后，发布到正式环境，执行迁移 0066；如果此前的迁移还没执行，也要一起执行。测试期间设置 `TELEPHONY_LIVE_ENABLED=true`，测完可以改回 `false`。
5. **快马后台。** 企业 API 已开通，有可用套餐和号码池；坐席已建好，坐席的接听手机已加入白名单；回调地址已由客服配置好。快马后台只由用户本人登录。
6. **测试方式。**
   - 企业 ID 和密钥通过安全输入框提供，不发在聊天里；
   - 被叫号码由用户明确授权；
   - 只打一通。

   要确认的结果：员工手机先响，接听后接通客户；挂断后话单推送回来，记录页显示已接通和时长；如果有录音，可以播放。
