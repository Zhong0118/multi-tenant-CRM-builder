# 快马回拨接入与联调边界

本功能面向公司管理员和员工：管理员绑定公司线路及员工坐席，员工从有权限的业务记录发起回拨，系统把结果关联回原记录。电话接通不自动进入询单，也不自动修改公海期限或成交保护。

本轮只进行本地模拟和自动化测试。真实线路联调、生产配置、部署需另行执行。不能将模拟通过描述为真实运营商线路通过。

## 已核对的供应商资料

2026-10-30 已在用户手动登录的快马后台只读核对：

- 企业管理 → 开发文档 → https://share.note.youdao.com/s/WynHdEp5
- 企业号码池中有一条“电信专线2”，拨打类型为“回拨”。
- 坐席有独立账号、主叫手机号、企业、组别和号码池配置。
- 先前提供的云升 SCRM PDF 使用不同 API 与签名方式，不可混用。

企业快捷模式 `POST /api/call/callBind`：

| 参数 | 含义 |
| --- | --- |
| company_id | 供应商分配的企业 ID，不是 CRM 租户 UUID |
| ts | 秒级时间戳，文档要求与服务器偏差不超过 10 秒 |
| sign | `MD5(company_id + app_secret + ts)` 的大写十六进制值 |
| api_type | `companyapi`，目前依据参数表；示例中的 `platform` 不一致，待确认 |
| type | `2` 表示回拨 |
| caller | 当前操作员工绑定的主叫手机号 |
| callee | 后端从获准的记录字段读取的客户手机号 |

成功 `code=1` 只表示受理并返回 `bind_id`，不表示客户接通。网络异常不能自动重试拨号。

话单推送 `push_type=1`，录音推送 `push_type=2`。话单中的 `status=1` 标为已接通，`status=0` 为未接通，`duration` 单位秒。成功接收须返回 `{"code":0}`，否则供应商可能重复推送。挂断事件只提供 `status=End`，不能独立推断接通。

## 真实联调前需供应商确认

1. 企业 ID、密钥、企业 API 开通及服务器 IP 白名单要求。
2. `api_type` / `platform` 的实际参数名，以及真实 POST 表单与回包示例。
3. 坐席如何继承企业号码池；现有加白手机号是否可直接用 API，是否另需套餐或坐席分配。
4. 接通状态和时长是否针对客户一侧；`bind_id` 的唯一范围与重用规则。
5. 回调地址由客服配置。本实现预留独立 Bearer 回调凭据，供应商是否支持该请求头尚未确认；不支持时必须实现双方确认的鉴权方式，不能去掉校验。
6. 话单/录音重试次数、顺序、回调来源和补查接口。当前这份文档没有列出历史话单查询接口。
7. “电信专线2”是否支持挂断通知；文档挂断支持列表没有列出该名称。
8. 录音 URL 的域名、有效期、访问授权和保留时间。

## 本地验收

测试环境采用独立数据库、独立 API/Web 端口、模拟线路。必须显式标识模拟，模拟不生成真实 CALL 活动或员工业绩。

管理员先配置模拟接入、员工主叫绑定与可拨打业务表字段，再切换到员工，从本人有权限的记录拨打。检查确认号码、同一请求去重、历史与原记录关联，以及权限被撤销后的号码和录音不可见。

自动化另覆盖错误回调凭据、跨租户、重复和乱序话单、网络超时待核实、停用成员/表和字段权限。

## 页面使用步骤

### 公司管理员配置

1. 打开公司工作区 → 设置 → 集成 → 电话外呼。
2. 在“接入配置”启用电话外呼。本地验收选择“本地模拟”，不需要真实企业密钥；“快马通讯”仍受服务器真实线路开关限制。
3. 在“成员坐席”找到操作人员，填写其供应商坐席号、已加白的接听手机号，开启外呼权限并保存。管理员自己拨打时也需要自己的坐席绑定。
4. 在“业务表字段”选择需要使用的已发布业务表，勾选存放客户电话的字段并保存。文本字段也可选，但实际拨打时必须包含有效的大陆手机号码；不要勾选客户名称等非电话内容。
5. 员工原有的记录和列权限仍然生效。配置电话字段不会给员工增加查看客户或隐藏列的权限。

### 员工拨打与跟进

1. 打开有权限的业务表，点击记录右侧电话图标；手机端在记录卡片右侧。记录详情顶部也有同一入口。
2. 在抽屉里核对自己的接听手机号、客户记录、电话字段及客户号码。有多个获准电话字段时先选择一个。
3. 勾选“我已核对主叫和被叫号码”，再点击确认按钮。本地模拟不会打到手机；真实线路完成联调后，员工先接听自己的回拨，线路商再连接客户。
4. “已受理”只表示供应商接受请求；最终话单回来才确定是否接通及通话时长。“提交结果待核实”不能直接重拨，避免重复打给客户。
5. 点击“返回记录继续跟进”，使用原有跟进功能记录沟通结果。一次通话不自动变成询单、成交，也不自动延长公海期限。
6. 在记录详情的“通话”标签查看该记录历史，或在左侧“通话记录”查看自己的通话。管理员可按成员、业务表、结果及日期筛选本公司的通话。

没有权限继续读取原记录或对应电话字段时，通话页不会通过历史记录绕过限制显示客户号码、录音或跳转链接。

确认后号码或接入方式若发生变化，服务端会拒绝用新号码创建通话，要求重新核对。网络重试保留原请求编号和确认内容，已保存的请求只返回原通话，不重复拨号。

## 凭据管理

企业密钥在管理员配置中输入，仅后端加密保存，不在读取接口、审计和日志中返回。服务器加密主密钥通过私密环境变量管理，不能提交 Git。空白密钥更新表示保留旧值。

真实拨打具有额外环境开关；拿到凭据后也不要直接打开，先完成上述供应商确认，再使用用户明确授权的测试号码验证一通回拨及最终话单。
