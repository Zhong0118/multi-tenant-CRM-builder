# 发给快马客服的问题清单

下面的文字可以整段复制给快马客服。问题按「不确认就打不了第一通电话」的优先级排列。对方回答后，把结论补进 [kuaima-telephony.md](kuaima-telephony.md)。

不要在这份文档或聊天里记录企业 ID、密钥或回调凭据。

---

您好，我们是山东百杰网络科技有限公司，正在把贵司的「企业快捷模式」回拨接口（`/api/call/callBind`）接入我们自己的 CRM 系统，想先确认以下几点：

**一、开通与账号**

1. 我们企业的 API 是否已经开通？企业 ID 和 app_secret 在后台哪里查看？如果需要重新生成，旧的会不会马上失效？
2. 调用接口需要 IP 白名单吗？如果需要，我们服务器的出口 IP 是 `62.234.18.169`，请帮忙加上。
3. 接口要求时间戳 `ts` 和贵司服务器相差不超过 10 秒，这个规定现在还有效吗？

**二、拨号参数**

4. 开发文档的参数表写的是 `api_type=companyapi`，示例里写的却是 `platform=companyapi`，到底用哪一个？我们现在两个都传，会有问题吗？
5. `caller` 是不是必须填坐席绑定的、已加入白名单的手机号？没有建坐席的手机号可以直接拨吗？
6. 坐席号 `seats_id` 是数字吗？在后台哪里查看？（我们看到文档里有 getSeatsList 接口）
7. 请求成功时返回 `{"code":1,"data":{"bind_id":"…"}}`，这个理解对吗？失败时 `msg` 里一般会写什么原因（比如套餐不足、号码不在白名单）？`bind_id` 是全局唯一，还是只在我们企业内唯一？会不会重复使用？

**三、话单、录音和挂断推送**

8. 请帮我们把话单推送地址配置成我们提供的地址。地址里带一个 `?token=` 参数用来校验身份，能保留这个参数吗？另外，能不能在请求头里加 `Authorization: Bearer`？
9. 推送用的是 JSON 还是表单格式？推送失败后会重试几次、间隔多久？我们回复 `{"code":0}` 就表示收到，这样对吗？
10. 话单里的 `status=1/0` 和 `duration`，指的是客户那一方有没有接通、通话多长，还是坐席那一方？时间字段是北京时间、格式为 `YYYY-MM-DD HH:mm:ss` 吗？
11. `telA` 和 `telB` 推送的是完整的 11 位手机号吗？`seats_id` 推送的是数字还是字符串？
12. 录音地址是什么域名？有效期多久、录音保留多久？访问录音需要授权吗？
13. 我们的号码池是「电信专线2」，支持挂断通知吗？（文档里支持挂断通知的列表没有写这个名称）
14. 如果推送丢了，有没有补查话单的接口？

**四、计费与测试**

15. 我们想先打一通测试电话：拨到员工手机、员工接听后再接通客户，这一通怎么计费？需要先购买套餐或者分配坐席吗？

谢谢！
